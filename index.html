  3. Compiler un TP en CSous Windows (MinGW, Git for Windows, WSL) et sous Linux : ce qui est installé sur le PC, ce qui manque, les commandes et les erreurs fréquentes.

  6. Quiz de démonstrationLes onze types de questions de l'outil de quiz.
  7. Atelier de démonstrationLes éditeurs des TD interactifs : diagrammes, tables, SQL, automates, chronogrammes.
