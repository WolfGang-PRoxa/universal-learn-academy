# Fenêtres et raccourcis

## Arrière-plan

Par défaut, fermer la fenêtre (la croix, **Ctrl+W**) ne quitte pas l’application : la fenêtre se cache, l’icône reste dans la zone de notification (en bas à droite de l’écran), et une génération de quiz en cours va à son terme.

- **Rouvrir** : clic sur l’icône, ou relancer l’application. Une seule instance tourne : la fenêtre se rouvre à la même page.
- **Menu de l’icône** (clic droit) : Ouvrir, Documentation, Rechercher les mises à jour, Quitter.
- **Quitter** : bouton d’alimentation tout en haut à droite des pages, entrée Quitter de l’icône, ou **Ctrl+Q**. L’application se ferme alors complètement. Si une génération de quiz est en cours, l’application demande d’abord confirmation.

Ce comportement se désactive dans [Paramètres › Arrière-plan](parametres:arriere-plan). Sous Linux, il dépend de la présence d’une zone de notification sur le bureau ; sans elle, la croix ferme l’application.

## Mises à jour

Les nouvelles versions sont publiées sur GitHub. L’application les recherche au démarrage, toutes les 6 heures et au réveil du PC, les télécharge en arrière-plan, l’annonce par une notification, puis les installe à sa fermeture. **Redémarrer et installer** (paramètres ou menu de l’icône) les applique tout de suite. Voir [Paramètres › Mises à jour](parametres:mises-a-jour).

## Raccourcis clavier

| Touches          | Action                      |
| ---------------- | --------------------------- |
| F1               | Documentation               |
| Ctrl+,           | Paramètres                  |
| Alt+Origine      | Accueil                     |
| Alt+← et Alt+→   | Page précédente et suivante |
| Ctrl+F           | Rechercher dans la page     |
| Ctrl+N           | Nouvelle fenêtre            |
| Ctrl+P           | Imprimer                    |
| Ctrl+Maj+S       | Enregistrer la page en PDF  |
| F5 ou Ctrl+R     | Recharger                   |
| Ctrl + et Ctrl − | Agrandir et réduire         |
| Ctrl+0           | Revenir à l’échelle choisie |
| F11              | Plein écran                 |
| Ctrl+W           | Fermer la fenêtre           |
| Ctrl+Q           | Quitter                     |

Dans la documentation, **Ctrl+F** place le curseur dans la recherche. Dans le paramétrage guidé, **Entrée** passe à l’étape suivante et **Échap** ferme le guide.

## La barre du haut

Sur chaque page, la barre du haut donne accès à l’accueil, au thème clair ou sombre, aux paramètres (roue dentée), à l’aide (**?**) et, si la synchronisation est en place, au bouton nuage.
