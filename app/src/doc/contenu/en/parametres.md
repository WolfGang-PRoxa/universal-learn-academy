# Settings

The settings open with the gear of the top bar, with **Ctrl+,** or with **File › Application settings…**. They appear in the courses window, over the page; the cross, **Esc** or a click outside the panel closes them. The button left of the title collapses or expands the list of sections. Each change applies as soon as it is made; a few require a restart, which the application then offers.

> **Tip** The [guided setup](guide:) presents the same settings one by one, with a short explanation.

## Language

Language of the menus, settings, home page and documentation: French or English. The change applies immediately to every window. [Open](parametres:langue)

## Help

Opens this documentation or the guided setup. [Open](parametres:aide)

## Updates

Shows the installed version. Enabled by default, updates are looked for at startup, every 6 hours and when the computer wakes up, downloaded in the background and installed when the application closes. **Restart and install** applies them immediately. [Open](parametres:mises-a-jour)

## Interface scale

Size of texts and buttons in every window. **Automatic** (100 %) suits most screens; otherwise from 50 to 200 %. **Ctrl +**, **Ctrl −** and **Ctrl + wheel** adjust further until the application closes; **Ctrl+0** returns to the chosen scale. [Open](parametres:affichage)

## Background

When enabled, closing the window only hides it: the application stays available through its notification area icon. When disabled, the close button quits the application. See [Background](page:application#background). [Open](parametres:arriere-plan)

## Window at startup

**Large window** (maximised on the main screen) or **Custom size and position**, set in a frame that represents the screens (mouse or arrow keys). If the position is no longer visible, the window opens maximised. [Open](parametres:fenetre)

## Shortcuts

Creates, repairs or replaces the shortcuts on the Desktop, in the Start menu (applications menu on Linux) or in any folder. [Open](parametres:raccourcis)

## AI assistant, Claude, ChatGPT and Gemini

Choice of the quiz assistant (Claude, ChatGPT or Gemini), connection to each and choice of models: see [Claude, ChatGPT and Gemini](page:claude). [Open](parametres:assistant)

## Profile

Active profile, creation (with a sample curriculum) and renaming. The home page can also switch profiles. [Open](parametres:profil)

## Data folder

Where downloaded courses and profile spaces are stored: `%LOCALAPPDATA%\Universal Learn Academy\donnees` by default, or any other folder. **Choose another folder…** switches folders without copying anything; **Move…** takes the data along: at the next start, it is copied to the chosen folder, the copy is checked, and only then is the old folder removed (nothing is deleted if something goes wrong). **Open the data folder** shows it in the file explorer. The change applies after a restart. Up to version 2.7 the default folder was `Documents/ULA`: it is moved automatically at the first launch of 2.8, unless it is a Git repository, which stays where it is. [Open](parametres:donnees)

## Sync

Syncing the data folder between several computers, when it is a Git repository: see [Sync](page:synchronisation). [Open](parametres:synchro)

## About

Versions, settings folder and logs folder, restarting the application. [Open](parametres:a-propos)
