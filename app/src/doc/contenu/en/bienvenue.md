# Welcome

Universal Learn Academy brings formatted courses, quizzes and interactive tutorials together in a desktop application. Courses are downloaded on demand from an online catalogue and arranged in a personal curriculum, and each profile’s progress is saved in its own folder.

This documentation has two parts:

- the **User guide**, for everyday use of the application;
- the **Technical documentation**, to understand how it works, its files and how to contribute.

## Where to start

1. Start the guided setup (button above): it presents the useful settings one by one.
2. Read [Getting started](page:premiers-pas) to create a profile and download the first courses.
3. Keep [Troubleshooting](page:depannage) at hand in case of trouble.

## Opening the help

| From | How |
|---|---|
| Any page | **F1** key, or the **?** button of the top bar |
| The menu | **Help › Documentation** or **Help › Guided setup…** |
| The settings | [Help](parametres:aide) card |

The search box, at the top of the contents (**Ctrl+F**), looks through every page of the documentation.

> **Note** Menus, settings, the home page and this documentation exist in French and English. Courses, quizzes and tutorials stay in the language they were written in. The language can be changed in [Settings › Language](parametres:langue).
