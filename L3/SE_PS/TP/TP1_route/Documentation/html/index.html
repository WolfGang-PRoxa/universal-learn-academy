Présentation

L'objectif de ce TP est de concevoir un système antio-collision pour des voitures circulant sur une route. Cette route est composée de 2 voies où les voitures circulent en sens contraire.

  • Les voitures sont des processus Unix qui lisent et écrivent lors de leur déplacements sur les voies
  • La route est un fichier

Le but est donc que les processus Unix ne fassent aucune écriture incohérente provoquant une collision dans le fichier route.

Objectifs

Ce TP à pour but de manipuler les verrous vus en cours. Il s'agit ici de gérer les lectures/écritures de deux types de processus

  • ceux qui seront codés par voiture.c et qui seront lancés plusieurs fois simultanément. Ils effectueront des lectures/écritures réglées par vos soins pour se déplacer dans le fichier route.
  • celui qui sera codé par vision.c qui sera lancé une seule fois et dont le but est d'afficher en permanence l'état de la route. Attention, pour que celui ci soit lisible, ne rafraichissez l'affichage uniquement quand le fichier route est modifié

Version 1

Les voitures avanceront sur une seule voie, sans chercher à doubler: à coder dans voiture_v1.c

Version 2

Les voitures plus rapides pourront doubler les plus lentes quand elles en auront la possibilité, c'est à dire qu'elles pourront avancer sur l'autre voie que celle où elles circulent initialement: à coder dans voiture_v2.c

Exemples

Afin de vous aider à réaliser les programmes d'affichage de la route et de déplacement des voitures vous pouvez vous inspirez des programmes du répertoire Exemples

  • ex_deplacement.c : déplacement séquentiel de voitures avec affichage de la route sans changer de voie jusqu'à ce que toutes les voitures soient arrivées ou qu'il y ait eu une collision
  • ex_depassement.c : déplacement de voitures avec changement de voie.

Organisation des fichiers sources

Les fichiers sont répartis dans les répertoires suivants

  • Verrous : répertoire dédié à vos programmes
  • Commun : fonctions, constantes communes à tous les TDA (Type de Donnée Abstrait)
  • Coord : TDA d'une coordonnée utilisée par les voitures, la route...
  • Voiture : TDA d'une voiture
  • Route : Fontions de gestion du fichier route avec ses deux voies
  • Exemples : Exemples de programmes faisant se déplacer des voitures séquentiellement avec et sans dépassement

On y trouve aussi divers fichiers pour la gestion du TP:

  • ROUTE.TAGS : fichier d'indexation des fonctions, constantes... (utile sous emacs)
  • les Makefile* : fichiers de compilation à utiliser avec make
  • Fichiers : répertoire dédié aux fichiers utilisés dans ce TP (comme le fichier route par exemple)

Utilisation

  1. Désarchivez et décompressez l'archive en faisant tar xvf TP_Route.tar.gz
  2. Allez dans le répertoire du TP et compilez le par cd TP_Route ; make -f Makefile all.
  3. Placez vous dans le répertoire dédié pour faire votre TP
    1. cd Verrous
    2. programmez dans les fichiers vision.c, voiture_v1.c, voiture_v2.c
    3. sans vous déplacer; compilez par make all
    4. Excécutez votre programme en faisant par exemple ./voiture_v1 ../Fichiers/route.bin A O L qui lance une voiture
      • sur le fichier route ../Fichiers/route.bin
      • avec la marque 'A'
      • dans le sens Ouest-Est
      • avec une vitesse Lente
    5. Vous pouvez utiliser tel quel le programme init_fich_route.c pour créer un fichier route, puis utiliser celui-ci dans vos programmes
