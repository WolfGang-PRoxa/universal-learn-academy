Présentation du Jeu

Ce Tp s'inpire du jeu de la course des motos du film Tron https://fr.wikipedia.org/wiki/Tron: un joueur pilote une moto sur une vaste piste en même temps que des motos pilotées par le système. Toutes les motos vont à la même vitesse et ne s'arrêtent jamais. Chaque moto laisse une trace pareille à un mur derrière elle. Si une moto s'écrase sur un mur (une trace de moto ou les limites de la piste) alors elle elle perd: celle-ci explose et sa trace disparait.

Le but est donc d'être la dernière moto en lice.

Objectifs

Ce TP à pour but de manipuler les outils de communication entre processus standards vus en cours. Il s'agit ici de faire communiquer 2 processus indépendants

  • celui qui exécutera la fonction pilote() qui gère les interactions avec l'utilisateur pour diriger sa moto
  • celui qui exécutera la fonction course() qui fait avancer toutes les motos du jeu sur une piste (celle de l'utilisateur comme les autres)

Ces processus seront gérés dans le programme tron.c que vous devrez donc programmer

Organisation des fichiers sources

Les fichiers sont répartis dans les répertoires suivants

  • Jeu : répertoire dédié à votre programme tron.c
  • Commun : fonctions, constantes communes à tous les TDA (Type de Donnée Abstrait)
  • Coord : TDA d'une coordonnée utilisée dans l'écran les motos, la piste...
  • Ecran : TDA écran géré par bibliothèque ncurses
  • Moto : TDA d'une moto
  • Mvt : TDA mouvement d'une moto sur la piste On y trouve aussi des tests d'affichage des ces mouvements sur la sortie standard et sur un écran géré par ncurses
  • Piste : TDA d'une piste

On y trouve aussi divers fichiers pour la gestion du TP:

  • TRON.TAGS : fichier d'indexation des fonctions, constantes... (utile sous emacs)
  • les Makefile* : fichiers de compilation à utiliser avec make

Utilisation

  1. Désarchivez et décompressez l'archive en faisant tar xvf TP_tron.tar.gz
  2. Allez dans le répertoire du TP et compilez le par cd TP_Tron ; make -f Makefile all. Eventuellment vérifiez que tout est bien compilé en effectuant les tests unitaires par make tests
  3. Placez vous dans le répertoire dédié pour faire votre TP
    1. cd Jeu
    2. programmez dans le fichier tron.c
    3. sans vous déplacer; compilez par make all
    4. Excécutez votre programme en faisant par exemple ./tron 10 30 5 M
