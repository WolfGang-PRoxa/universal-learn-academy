Detailed Description

Fonctions sur la gestion d'un fichier représentant un lieu de stockage
Format :

  • capacité (int)
  • nombre de produits (int)

Attention: la représentation d'un int pouvant varier selon la machine, il est conseillé de réinitialiser un stock à chaque changement de machine
