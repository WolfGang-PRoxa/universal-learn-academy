CrowdFrame => dessine chaque displayable (fait appel à la méthode paint de chaque displayable)
CrowGame => Constructeur : créer chaque personne (soit travailleur, soit touriste)
Run => faire appel au move de chaque personne
getDisplayable => retourner la liste des personnes

Personne est un Displayable :
Attributs :
Displayable : des coordonnées (x,y), une couleur 
Personne : le crowdGame, 
	une vitesse => 10, 
	un dx, un dy (angle) (sera défini par les Touristes et les Travailleurs)

- chaque Displayable dispose d'une méthode paint : affiche un rond avec une couleur
	- Personne doit en plus afficher un segment représentant sa direction :
	g.setColor(...)
	x_arrivee = (int) this.x+this.dx*lentrait*this.radius)
	y_arrivee = (int) (this.y+this.dy*lentrait*this.radius)
	g.drawline(x_depart, y_depart, x_arrivee, y_arrivee);

- il possède une méthode move pour se déplacer (en fonction d'une vitesse et d'un angle)
(Mise à jour de x, y)

Travailleur est une Personne :
dx dy passés en paramètre
Attributs : int x, int y, double dx, double dy, CrowdGame g
Speed 15
Utilise le move de Personne

Toursiste est une Personne :
Attributs : int x, int y,  CrowdGame g
Speed 5
Tire un angle aléatoirement (radians => 0 à 2*pi), positionne dx dy (radians)
Override le move (tirer angle aléatoire)
