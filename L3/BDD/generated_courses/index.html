Bases de données

Concevoir une base de données relationnelle, du diagramme de classes UML au modèle relationnel, puis l'exploiter en SQL et la programmer en PL/pgSQL.

Enseignants
Théo Mariotte (responsable), Mathilde Mottay
Volume
3 CM · 4 TD · 5 TP + 1 TP noté
Évaluation
écrit 67 % · TP noté 33 %

Cours

  1. 01 Du diagramme de classes au modèle relationnelClasses, associations et multiplicités ; formes normales ; les cinq règles de traduction. Cours
  2. 02 Le langage SQL : requêtes, tables et fonctionsINSERT, UPDATE, DELETE ; SELECT et ses clauses ; bases, schémas, tables, contraintes et vues ; fonctions SQL. Cours
  3. 03 SQL avancé : droits, CTE, fenêtrage, PL/pgSQL et triggersSéquences et index ; rôles, GRANT et REVOKE ; CTE et CTE récursives ; fonctions de fenêtrage ; fonctions PL/pgSQL et triggers. Cours

TD

  1. 01 Modèles entités-associationsInteractif · critiquer et corriger un diagramme, le traduire en relationnel, 8 requêtes SQL exécutées (films et cinéma, plateforme de jeux) TD
  2. 02 La compagnie SW7Interactif · diagramme de classes et modèle relationnel (celui de l'enseignant en correction), deux tables et leurs contraintes testées, puis 8 requêtes et une fonction sur la base de l'enseignant : CTE, RANK, LAG, generate_series ; commandes de gestion TD
  3. 03 La gestion d'HalloweenInteractif · sujet du CC 2023 : diagramme de classes, modèle relationnel, commandes d'exploitation, puis une table, deux requêtes, une vue et deux fonctions SQL et PL/pgSQL, exécutées et testées TD
  4. 04 Winter RaveInteractif · sujet de l'évaluation de décembre 2025 : diagramme de classes, modèle relationnel, requêtes avec CTE et fenêtrage, deux fonctions SQL exécutées et testées, commandes de gestion et de droits TD

Les TD interactifs se font dans la page : dessin ou texte, contrôles, comparaison à la solution. Avec le serveur local, le travail est enregistré, le SQL s'exécute et Claude peut aider ou corriger.

TP

  1. 01 Plateforme de jeuxSujet, modèles, connexion à PostgreSQL, les 33 questions, et une console SQL pour travailler chez soi : le compte rendu entier rejoué sur une base neuve TP
  2. 02 Plateforme de jeux (suite)Schémas, fonctions SQL, séquence, CTE et fenêtrage, rôles et privilèges, premiers pas en PL/pgSQL, et une console SQL qui rejoue la base du TP 1 et le compte rendu TP
  3. 03 La compagnie SW7Implémentation dans deux schémas, CTE, fenêtrage et CTE récursive, sujet d'examen de 2020 (vue, fonctions, trigger), exploitation, et une console SQL pour travailler chez soi TP
  4. 04 La compagnie SW7 (suite)Dernier TP avant le TP noté : CTE et fenêtrage, table zone, exploitation, fonctions et trigger, avec deux consoles SQL où la base du TP 3 est chargée TP

Quiz

  1. Q1 Du diagramme de classes au modèle relationnel22 questions sur le cours 1 : multiplicités, formes normales, règles de traduction, avec un diagramme de classes à dessiner et un modèle relationnel à écrire Quiz
  2. Q2 Le langage SQL18 questions sur le cours 2, dont 5 requêtes exécutées et corrigées automatiquement Quiz
  3. Q3 SQL avancé et PL/pgSQL28 questions sur le cours 3 : droits, CTE et CTE récursives, fenêtrage, PL/pgSQL et triggers, dont 8 écritures de code exécutées sur la base Dingo Fringo Quiz
  4. SQL SQL à écrire15 requêtes exécutées pour préparer le TP noté : jointures, regroupements, sous-requêtes, division, contraintes, vue, mise à jour Quiz
  5. FN Formes normales13 questions du cours 1 : dépendances fonctionnelles, forme normale d'une relation, et 4 relations à décomposer jusqu'à la 3NF Quiz
  6. PL PL/pgSQL et triggers13 questions du cours 3, dont 10 écritures de code exécutées sur la base Dingo Fringo : boucles, RETURN QUERY, RETURN NEXT, exceptions, triggers Quiz
  7. Écrit Révision générale, au format de l'écrit38 questions sur un sujet neuf, les refuges du Givré : trois diagrammes de classes et un modèle relationnel ordonné, 9 requêtes et fonctions SQL exécutées, questions de cours en trois mots Quiz

Avec le serveur local (studies/lancer.bat), les quiz gardent tes tentatives, exécutent le code et donnent accès à Claude.

Organisation du module

  • Intervenants : Théo Mariotte, responsable du module (2 CM, 4 TD, 4 TP et le TP noté, pour tous les groupes) ; Mathilde Mottay, de Groupama (1 CM et 1 TP, pour tous les groupes).
  • Évaluation écrite, 67 % : 1 h 30, modélisation et exploitation, plus des questions de cours sur la partie de Mathilde Mottay.
  • TP noté, 33 % : 2 h, exploitation d'une base de données. La note est conservée en session 2.
  • UMTICE : cours « Bases de données 2 », clé d'inscription L3BDDBG. Tous les supports y sont déposés, ainsi que le rendu du TP noté.
