Classes Ruby et polymorphisme

On ajoute des méthodes aux classes de Ruby (Integer, String, Array), on écrit une classe de nombres rationnels, puis une hiérarchie de pokémons comparables, leur collection énumérable et une capacité partagée par un module. Pour finir, six méthodes à écrire avec reduce.

Objectifs

  • Rouvrir une classe existante de Ruby pour lui ajouter des méthodes.
  • Écrire une classe de valeurs (les rationnels) dont les opérations rendent de nouveaux objets.
  • Concevoir une hiérarchie polymorphe, la rendre comparable (Comparable) et sa collection énumérable (Enumerable).
  • Donner une capacité à quelques classes seulement, par un module qui porte des variables d'instance.
  • Exprimer un parcours avec reduce.

Notions utilisées

  • Blocs et yield, reduce, Comparable, Enumerable (cours 4)
  • Les modules Ruby : include, variables d'instance d'un module
  • Héritage, classes abstraites (cours 3)

Diviseurs et nombres rationnels TD, sujet 1

Sujet 1 Reprise de l'exercice du TP 1 et du cours sur les diviseurs (des maths)

Des maths ! Ajoutez à la classe Integer de Ruby les trois méthodes suivantes :

  1. listeDesDiviseurs() qui retourne dans un tableau la liste des diviseurs de a. Exemple : pour a=6 on obtient la liste (1,2,3,6).
  2. listeDesNonsDiviseurs() qui retourne dans un tableau la liste des non diviseurs de a. Exemple : pour a=6 on obtient la liste (4,5).
  3. RapDivNonDiv() calcule et retourne le rationnel représentant le rapport entre la somme des diviseurs de a (inférieurs à a) et la somme des nonsDiviseurs de a. Pour a=6 le résultat est 6/9 : 6 a pour diviseurs inférieurs à 6 : 1, 2, 3 et la somme de ceux-ci vaut 6 ; 6 a pour non diviseurs inférieurs à 6 : 4 et 5 et la somme de ceux-ci vaut 9.

On souhaite manipuler ce rapport sous la forme d'un nombre rationnel, donc de la forme a/b où a/b est une fraction irréductible (a/b est irréductible si elle n'est plus simplifiable). Dans l'exemple précédent on préfèrera donc afficher 2/3 plutôt que 6/9.

Pour cela on vous demande de donner le code de la classe NR qui fournit quelques opérations simples sur les nombres rationnels. Les opérations retourneront toujours les résultats sous forme de fractions irréductibles. La classe NR permettra de réaliser les opérations suivantes :

  • Construire un rationnel irréductible associé au nombre rationnel a/b : NR.simplifier(6,9) permet de créer un rationnel dont le numérateur est 2 et le dénominateur 3.
  • ajouter, multiplier, soustraire et diviser par un rationnel.
  • afficher un rationnel et déterminer si deux rationnels sont égaux.

Vos classes doivent permettre d'exécuter le programme Ruby suivant :

######## Programme de Test ########
puts "\n\tTest de la classe Integer"
puts "\t=========================="
print "Les Diviseurs de 6      = "
p 6.listeDesDiviseurs()
print "Les Nons Diviseurs de 6 = "
p 6.listeDesNonsDiviseurs()
print "Le raport des deux      = "
puts 6.rapDivNonDiv()

puts "\n\tTest de la classe NR"
puts "\t===================="
a=NR.simplifier(6,9)
b=NR.simplifier(5,3)
c=NR.simplifier(15,18)
d= NR.simplifier(5,20)
puts "(#{a}) + (#{b}) = #{e=a.ajouter(b)}"
puts "(#{e}) - (#{c}) = #{f=e.soustraire(c)}"
puts "(#{f}) / (#{d}) = #{g=f.diviser(d)}"
puts "(#{e}) / (#{e}) = #{g.diviser(g)}"
	Test de la classe Integer
	==========================
Les Diviseurs de 6      = [1, 2, 3, 6]
Les Nons Diviseurs de 6 = [4, 5]
Le raport des deux      = 2/3

	Test de la classe NR
	====================
(2/3) + (5/3) = 7/3
(7/3) - (5/6) = 3/2
(3/2) / (1/4) = 6
(7/3) / (7/3) = 1

Remarque Deux détails du programme de test À vérifier

Le texte nomme la troisième méthode RapDivNonDiv, le programme l'appelle rapDivNonDiv : c'est ce second nom qu'il faut définir. La dernière ligne affiche « (7/3) / (7/3) » mais calcule g.diviser(g), soit 6 / 6 : le résultat est 1 dans les deux cas.

Indice

(1..self).select { … } garde les entiers qui vérifient une condition ; reject garde les autres. Pour simplifier une fraction, on divise ses deux termes par leur plus grand commun diviseur : Ruby le donne par a.gcd(b).

char * enleveStr(char * s1, const char * s2){
   char * p;
      while (p = strstr(s1, s2)){
           strcpy(p, p + strlen(s2));
      }
   return s1;
}

Sujet 2 · 7 Évaluation d'expression

  1. Ajouter à la classe String les méthodes suivantes :
    • isDigit?() une méthode qui retourne vrai si la chaîne est un chiffre ;
    • isSeparator?() une méthode qui retourne vrai si la chaîne représente un séparateur ;
    • digitValue() une méthode qui renvoie l'entier correspondant au chiffre.
  2. Ajouter une méthode evaluePostfixe à la classe String qui renvoie le résultat de l'évaluation de l'expression postfixée contenue dans la chaîne receveuse. Ex : "128 12+10-2*".evaluePostfixe => 260

Rappel de l'algorithme d'évaluation :

s est une chaine qui contient une expression postfixée (on ne vérifie pas)
1) parcours de s
     si le caractère courant est un chiffre
       alors ajouter ce chiffre au nombre déjà lu
     sinon
       empiler le nombre lu
       remettre le nombre a 0
       si le caractère courant est un séparateur (espace, tab, cr et...)
         alors rien
         sinon (c'est un opérateur)
           dépiler dans opérande droit
           dépiler dans l'opérande gauche
           appliquer l'opérateur aux deux opérandes
           empiler le résultat
2) retourner le sommet de pile

Attention Un nombre lu n'existe pas toujours

Pris à la lettre, l'algorithme empile « le nombre lu » à chaque caractère qui n'est pas un chiffre, même quand aucun chiffre ne précède : dans "128 12+10-2*", l'opérateur + suit 12, mais - suit 10 et * suit 2, et l'espace après 128 est suivie de 1. Un opérateur qui suit un autre opérateur ("3 4 5*+") empilerait un 0 de trop. Il faut donc n'empiler que si au moins un chiffre a été lu depuis le dernier empilement.

Les pokémons TD, sujet 3

Sujet 3 Les Pokemons, questions 1 à 3

Les Pokémons sont des gentils animaux qui sont passionnés par la programmation objet en général et par le polymorphisme en particulier. Il existe quatre grandes catégories de pokémons :

  • Les sportifs : ces pokémons sont caractérisés par un nom, un poids (en kg), un nombre de pattes, une taille (en mètres) et une fréquence cardiaque mesurée en nombre de pulsations à la minute. Ces pokémons se déplacent sur la terre à une certaine vitesse que l'on peut calculer grâce à la formule suivante : vitesse = nombre de pattes * taille * 3
  • Les casaniers : ces pokémons sont caractérisés par un nom, un poids (en kg), un nombre de pattes, une taille (en mètres) et le nombre d'heures par jour où ils regardent la télévision. Ces pokémons se déplacent également sur la terre à une certaine vitesse que l'on peut calculer grâce à la formule suivante : vitesse = nombre de pattes * taille * 3
  • Les marins : ces pokémons sont caractérisés par un nom, un poids (en kg) et un nombre de nageoires. Ces pokémons ne se déplacent que dans la mer à une vitesse que l'on peut calculer grâce à la formule suivante : vitesse = poids / 25 * nombre de nageoires
  • Les croisières : ces pokémons sont caractérisés par un nom, un poids (en kg) et un nombre de nageoires. Ces pokémons ne se déplacent que dans la mer à une vitesse que l'on peut calculer grâce à la formule suivante : vitesse = (poids / 25 * nombre de nageoires) / 2

On doit pouvoir afficher toutes les caractéristiques et comparer les Pokemons suivant leur vitesse.

  • Sur un pokémon sportif : "Je suis le pokémon Pikachu mon poids est de 18 kg, ma vitesse est de 5,1 km/h j'ai 2 pattes, ma taille est de 0,85m ma fréquence cardiaque est de 120 pulsations à la minute"
  • Sur un pokémon casanier : "Je suis le pokémon Salameche mon poids est de 12 kg, ma vitesse est de 3,9 km/h j'ai 2 pattes, ma taille est de 0,65m je regarde la télé 8h par jour"
  • Sur un pokémon marin : "Je suis le pokémon Rondoudou mon poids est de 45 kg, ma vitesse est de 3,6 km/h j'ai 2 nageoires"
  • Et enfin sur un pokémon de croisière : "Je suis le pokémon Bulbizarre mon poids est de 15 kg, ma vitesse est de 0,9 km/h j'ai 3 nageoires"
  1. Proposer un diagramme de classes PROPRE LISIBLE ET COMPLET représentant les classes nécessaires.
  2. Programmer ces classes en Ruby.
  3. Écrire un programme de test qui mettent en œuvre les fonctionnalités développées.
Indice

Sportifs et casaniers partagent leurs caractéristiques et leur formule de vitesse : une classe intermédiaire, abstraite, les regroupe. Un croisière est un marin deux fois plus lent. Pour comparer suivant la vitesse, une seule méthode <=> et le module Comparable.

Sujet 3 Les séances de détente, questions 5 à 7

À l'inverse des Sportifs et des Marins, les pokémons Casaniers et de Croisière peuvent participer à des séances de détente : les premiers devant la télévision, les seconds au cours de leurs promenades en mer. Pour chaque Pokémon concerné, on souhaite pouvoir :

  • enregistrer une séance de détente en précisant sa durée en minutes ;
  • consulter le nombre de séances effectuées ;
  • connaître la durée totale consacrée à ces séances.

Un pokémon qui n'a encore participé à aucune séance doit avoir un nombre de séances et une durée totale nuls.

  1. Proposez une solution qui permette d'implémenter ces fonctionnalités et complétez votre diagramme de classes.
  2. Programmez cette solution en Ruby.
  3. Écrire un programme de test illustrant le fonctionnement de votre solution.
Indice

Jouons avec reduce TD, sujet 4

Sujet 4 Jouons avec reduce

Le sujet rappelle la documentation de reduce (module Enumerable, Ruby 2.7.3) : reduce(initial, sym), reduce(sym), reduce(initial) { |memo, obj| block }, reduce { |memo, obj| block } ; inject et reduce sont synonymes. À chaque élément, le bloc reçoit l'accumulateur (memo) et l'élément, et sa valeur devient le nouvel accumulateur ; sans valeur initiale, le premier élément sert d'accumulateur de départ. Exemples :

# Sum some numbers
(5..10).reduce(:+)                              #=> 45
# Same using a block and inject
(5..10).inject { |sum, n| sum + n }             #=> 45
# Multiply some numbers
(5..10).reduce(1, :*)                           #=> 151200
# Same using a block
(5..10).inject(1) { |product, n| product * n }  #=> 151200
# find the longest word
longest = %w{ cat sheep bear }.inject do |memo, word|
   memo.length > word.length ? memo : word
end
longest                                         #=> "sheep"

Toutes ces méthodes doivent être écrites en utilisant la méthode reduce du module Enumerable.

  1. Écrire une méthode produit de la classe Array permettant de faire le produit des éléments (on suppose que les éléments du tableau sont multipliables entre eux). [12,6,3,10,5,16,8,4,2,1].produit → 11059200
  2. Écrire une méthode element? de la classe Array permettant de savoir si un élément appartient au tableau. [12,6,3,10,5,16,8,4,2,1].element?(10) → true ; [12,6,3,10,5,16,8,4,2,1].element?(49) → false
  3. Écrire une méthode monMap de la classe Array permettant de parcourir le tableau et dont le résultat est un Array contenant les résultats d'application du bloc sur chacun des éléments (bref il s'agit de réécrire collect (ou map)). (1..10).to_a.monMap {|x| x*x} → [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]
  4. Écrire une méthode maximum de la classe Array permettant de retourner le maximum d'un Array. [12,6,3,10,5,16,8,4,2,1].maximum → 16
  5. Écrire une méthode monReverse de la classe Array permettant de renverser un Array. [12,6,3,10,5,16,8,4,2,1].monReverse → [1, 2, 4, 8, 16, 5, 10, 3, 6, 12]
  6. Écrire une méthode monFilter de la classe Array permettant de filtrer les éléments d'un Array satisfaisant un critère (bref réécrire select).
    • (1..10).to_a.monFilter {|x| x%2==0} → [10, 8, 6, 4, 2]
    • ["Hubert","Janine","Juliette","Agathe"].monFilter {|x| x.include? "a"} → ["Agathe", "Janine"]
    • ["Hubert","Janine","Juliette","Agathe"].monFilter {|x| x.include? "a"} → ["Juliette", "Hubert"]
    • ["Hubert","Janine","Juliette","Agathe"].monFilter {|x| x.include? "a"} → ["Juliette", "Janine"]

Remarque Les exemples de monFilter À vérifier

Les trois derniers exemples ont le même bloc et trois résultats différents : les deux derniers correspondent en fait à x.include? "u" (Hubert, Juliette) et à x.include? "J" (Janine, Juliette). Tous les résultats sont aussi donnés dans l'ordre inverse du tableau : select rendrait [2, 4, 6, 8, 10]. C'est le résultat d'un reduce qui place chaque élément gardé devant l'accumulateur, comme monReverse. La question dit « réécrire select » : la solution proposée garde l'ordre, et donne la variante de l'énoncé.

À retenir

Les méthodes

  • En Ruby, une classe reste ouverte : class Integer … end ajoute des méthodes à tous les entiers, self désignant le receveur.
  • Une classe de valeurs (les rationnels) garde ses objets sous une forme normale (fraction irréductible, signe au numérateur) : l'égalité se réduit alors à celle des termes.
  • Définir <=> et inclure Comparable donne <, >, between? et le tri ; définir each et inclure Enumerable donne sort, collect, select, reduce…
  • Une capacité partagée par des classes sans ancêtre commun propre va dans un module ; ses variables d'instance vivent dans chaque objet, et une initialisation paresseuse (@x ||= 0) les rend nulles sans rien demander aux classes.
  • reduce parcourt une collection en transportant un accumulateur : somme, produit, maximum, construction d'un tableau (acc << x garde l'ordre, [x] + acc l'inverse).
  • Attention à la division entière : 45 / 25 vaut 1 ; écrire 45 / 25.0.

Auto-évaluation

Que vaut NR.simplifier(2, -4) avec la solution proposée, et pourquoi ?

-1/2 : le pgcd vaut 2, et on le prend négatif quand le dénominateur l'est, pour que le signe passe au numérateur.

Pourquoi la classe de la file ne s'appelle-t-elle pas File ?

File existe déjà en Ruby (les fichiers) : écrire class File rouvrirait cette classe au lieu d'en créer une.

Que faut-il écrire pour que pikachu > salameche compare les vitesses ?

include Comparable dans Pokemon, et une méthode <=>(autre) qui rend vitesse <=> autre.vitesse.

Pourquoi la détente est-elle un module et non une classe de la hiérarchie ?

Casanier hérite de Terrestre et Croisière de Marin ; leur seul ancêtre commun, Pokemon, est aussi celui des sportifs et des marins, qui ne doivent pas avoir la capacité. Ruby n'a pas d'héritage multiple : un module inclus dans les deux classes la leur donne.

Que rend [3, 1, 2].reduce([]) { |acc, x| [x] + acc } ?

[2, 1, 3] : chaque élément est placé devant les précédents, le tableau est renversé.
