Introduction à l'IOS Cisco

En TP, on configure de vrais routeurs et commutateurs Cisco. Cette annexe présente ce qu'il y a dans la boîte (les mémoires et leur rôle), comment s'y connecter, et comment se déplacer dans l'interface en ligne de commande : modes, aide, abréviations, et la différence capitale entre configuration courante et configuration de démarrage.

Qu'est-ce que l'IOS ? diapos 2–3

Définition IOS

L'IOS (Internetwork Operating System) est le système d'exploitation des équipements Cisco. Une image IOS est le fichier qui le contient.

Comme tout système, un équipement Cisco se compose :

  • du matériel (les composants physiques) ;
  • d'un noyau, le système lui-même ;
  • d'un shell, l'interface utilisateur : graphique (GUI) ou en ligne de commande (CLI), de loin la plus utilisée.

L'IOS gère le matériel et les interfaces, et offre des services : routage, sécurité (pare-feu), DHCP, NAT, serveur web… Il doit être maintenu à jour, pour les correctifs de sécurité ou pour ajouter des fonctions (diapo 9).

Le matériel des salles de TP (diapo 3) : des routeurs Cisco 1700 (avec deux cartes d'extension Ethernet) et RV320 (un port WAN, quatre ports Ethernet), des commutateurs Cisco des gammes 200 et 300, HP et Netgear.

Les composants matériels diapos 4–8

Un routeur est un ordinateur. On y retrouve un processeur (CPU) qui exécute le système, et quatre sortes de mémoire, chacune avec son équivalent sur un PC :

MémoireVolatile ?ContenuÉquivalent PC

Attention Ce qui se perd à la coupure

Toute modification tapée en CLI va dans la configuration courante, en RAM. Si le routeur s'éteint avant qu'on l'ait copiée en NVRAM, elle est perdue.

La séquence de démarrage diapos 10 et 18

  1. Charger le bootstrap depuis la ROM et tester le matériel (POST : diagnostic des mémoires et des modules).
  2. Lire le registre de configuration et chercher l'image IOS (en flash en général), la vérifier et la démarrer.
  3. Charger la configuration de démarrage depuis la NVRAM (startup-config), qui devient la configuration courante.

Complément Et sans configuration ? Ajout

Si la NVRAM est vide (routeur neuf ou effacé avec erase startup-config), l'IOS propose un dialogue de configuration initiale (« Would you like to enter the initial configuration dialog? ») ; on répond no pour configurer à la main. Le registre de configuration sert notamment à démarrer en ignorant la NVRAM, pour récupérer un équipement dont on a perdu le mot de passe.

Se connecter au routeur diapos 11–14

On peut atteindre un routeur par plusieurs chemins (diapo 11) : un terminal sur la ligne console ; un modem sur la ligne auxiliaire ; par le réseau Ethernet, un terminal virtuel (Telnet ou SSH), un serveur TFTP (pour charger images et configurations) ou un navigateur web.

Définition Port console

Solution par défaut, qui marche même sur un équipement neuf sans adresse IP : un câble « console », avec un connecteur série d'un côté et un RJ45 de l'autre, relie le port console de l'équipement à un terminal série, physique ou logiciel (HyperTerminal sous Windows, PuTTY…).

Les abréviations

Toute commande peut être abrégée tant que l'abréviation n'est pas ambiguë :

router#conf t
router(config)#int e0
router(config-if)#ip addr 196.200.1.1 255.255.255.0

conf t pour configure terminal, int e0 pour interface ethernet 0, ip addr pour ip address. La touche Tab, elle, écrit le mot en entier :

Router(config)#int<TAB>
Router(config)#interface et<TAB>
Router(config)#interface ethernet 0
Router(config-if)#ip add<TAB>
Router(config-if)#ip address

Le nom des interfaces

Une interface se désigne par un type, un emplacement (slot : 0, 1, 2, 3) et un numéro dans cet emplacement (0, 1), par exemple e0/0. Les types s'abrègent :

Les modes de commande diapos 19–22

Les commandes disponibles dépendent du mode, que l'invite indique. Examen

ModeInvitePour quoi faire
UtilisateurRouter>Mode à la connexion : consulter, sans rien modifier.
PrivilégiéRouter#Toutes les commandes de consultation, sauvegarde, redémarrage ; on y entre par enable (et un mot de passe).
Configuration globaleRouter(config)#Commandes qui portent sur tout le routeur.
InterfaceRouter(config-if)#Commandes propres à une interface.
LigneRouter(config-line)#Commandes propres à une ligne (console, vty…).
RoutageRouter(config-router)#Commandes d'un protocole de routage.

Pour entrer dans un mode spécifique, depuis la configuration globale :

  • interface {type} {numéro} passe en configuration d'interface (type : e, fa, gi) ;
  • router {protocole} [option] passe en configuration du routage (protocole : rip, ospf…) ;
  • line {console|vty} {numéros} passe en configuration d'une ligne.

Les fichiers de configuration diapos 23–25

Un routeur a toujours deux configurations : Examen

Configuration courante (running-config)

  • En RAM ; c'est celle qui s'applique en ce moment.
  • Modifiée par chaque commande de configuration.
  • Affichée par show running-config.

Configuration de démarrage (startup-config)

  • En NVRAM ; chargée au démarrage.
  • Mise à jour seulement par copy running-config startup-config.
  • Affichée par show startup-config.

Un extrait de show running-config (diapo 24) : chaque ligne est une commande de configuration globale, les ! servent de séparateurs.

Current configuration : 894 bytes
!
version 12.4
service timestamps debug datetime msec
service timestamps log datetime msec
no service password-encryption
!
hostname Router
!
enable password cisco
!
ip subnet-zero
ip cef

On y lit, par exemple, le nom de l'équipement (hostname) et le mot de passe du mode privilégié, ici en clair (enable password cisco, avec no service password-encryption).

Complément Une configuration de base complète Ajout

Les commandes à connaître pour démarrer un TP : nommer l'équipement, protéger les accès, adresser une interface, vérifier, sauvegarder.

Router> enable
Router# configure terminal
Router(config)# hostname R1
R1(config)# enable secret Cl4ss3
R1(config)# line console 0
R1(config-line)# password c0ns0le
R1(config-line)# login
R1(config-line)# exit
R1(config)# interface gi0/0
R1(config-if)# ip address 192.168.1.1 255.255.255.0
R1(config-if)# no shutdown
R1(config-if)# end
R1# show ip interface brief
R1# show ip route
R1# copy running-config startup-config
  • enable secret stocke le mot de passe chiffré, contrairement à enable password.
  • Les interfaces d'un routeur sont éteintes par défaut : sans no shutdown, rien ne passe.
  • show ip interface brief résume l'adresse et l'état (up/down) de chaque interface.
  • Pour exécuter une commande du mode privilégié depuis un mode de configuration, la précéder de do : R1(config)# do show ip route.

Exercices

Exercice 1 Où est-ce rangé ?

Pour chaque élément, donner la mémoire qui le contient : (a) la table ARP ; (b) l'image IOS ; (c) la configuration qui sera chargée au prochain démarrage ; (d) le programme du POST ; (e) une route statique que l'on vient de taper.

Solution proposée

(a) RAM. (b) Flash. (c) NVRAM. (d) ROM. (e) RAM (configuration courante), tant qu'on ne l'a pas sauvegardée.

Exercice 2 Reconnaître le mode

Dans quel mode est-on, et comment y est-on arrivé, avec les invites R1>, R1(config-if)#, R1(config-router)#, R1# ?

Solution proposée
  • R1> : utilisateur, à la connexion.
  • R1(config-if)# : configuration d'interface, par enable, configure terminal, interface ….
  • R1(config-router)# : configuration du routage, par enable, configure terminal, router rip (par exemple).
  • R1# : privilégié, par enable.

Exercice 3 Le TP perdu

Un étudiant configure les adresses de son routeur, teste avec succès, puis éteint le routeur. Le lendemain, plus rien ne marche. Que s'est-il passé ? Quelle commande a-t-il oubliée, et dans quel mode se tape-t-elle ?

Solution proposée

Sa configuration n'était qu'en RAM (configuration courante), effacée à la coupure ; au démarrage, le routeur a rechargé l'ancienne configuration de la NVRAM. Il fallait taper copy running-config startup-config en mode privilégié (ou do copy running-config startup-config depuis un mode de configuration).

Exercice 4 Écrire la configuration

Depuis l'invite Router>, écrire les commandes qui nomment le routeur R2, donnent l'adresse 10.1.1.254/24 à l'interface fa0/1, l'activent, puis sauvegardent.

Solution proposée 
Router> enable
Router# configure terminal
Router(config)# hostname R2
R2(config)# interface fa0/1
R2(config-if)# ip address 10.1.1.254 255.255.255.0
R2(config-if)# no shutdown
R2(config-if)# end
R2# copy running-config startup-config

À retenir

L'essentiel

  • IOS = système d'exploitation des équipements Cisco ; on le pilote surtout en CLI.
  • RAM (volatile) : configuration courante, tables de routage et ARP. NVRAM : configuration de démarrage. Flash : image IOS. ROM : bootstrap et POST.
  • Démarrage : bootstrap et test du matériel ; registre de configuration et recherche de l'IOS ; chargement de la configuration.
  • Connexion par défaut : câble console, terminal série (9600 bauds, 8 bits, sans parité, 1 bit d'arrêt, sans contrôle de flux, sur un 1700).
  • Aide : ? ; abréviations (conf t) ; Tab pour compléter. Interfaces : type + emplacement/numéro (gi0/0).
  • Modes : utilisateur >, privilégié # (enable), configuration globale (config)# (configure terminal), puis interface, ligne, routage.
  • Toute modification va dans la running-config ; copy running-config startup-config pour la garder au redémarrage.

Auto-évaluation

Dans quelle mémoire est stockée la configuration de démarrage ?

La NVRAM.

Quel est l'équivalent du BIOS d'un PC sur un routeur ?

Quelle commande fait passer du mode utilisateur au mode privilégié ?

enable.

Que signifie l'invite Router(config-line)# ?

Comment afficher la configuration en cours ?
