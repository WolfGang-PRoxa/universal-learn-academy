TD

Le TD (automne 2024) se fait sur papier, en quatre parties : I, vecteurs dans un espace euclidien ; II, espaces vectoriels ℝⁿ ; III, suites de réels ; IV, intégration.

TP

Les TP se font dans des notebooks Jupyter : lancer lancer-jupyter.bat (ou lancer-jupyter.sh) à la racine de studies, puis ouvrir le notebook dans son dossier. Chaque notebook reprend l'énoncé question par question, avec une cellule de code vide sous chaque question.

  • TP 1 · pivot de Gauss : opérations sur les lignes, inversion, test de rapidité contre numpy.linalg, résolution de système (énoncé, algorithme)
  • TP 2 · autour du déterminant : développement récursif, comatrice, inverse, fonctions passées en argument (énoncé)
  • TP 3 · approximation d'intégrales : rectangles, trapèzes, Monte-Carlo (énoncé)
  • TP 4 · recherche de zéros : dichotomie, méthode de Newton, extremum, failles des deux méthodes (énoncé)

Les corrections des TP 1 et 2 (TP1 Correction.py, Correction TP2.py) restent dans leur dossier, à part des notebooks. Installation et erreurs fréquentes : les notebooks Python.
