Pointeurs, allocation dynamique et structures

Un pointeur contient une adresse : il permet à une fonction de modifier une variable, de parcourir un tableau ou une chaîne, et de réserver de la mémoire pendant l'exécution avec malloc. Les structures, enfin, regroupent sous un seul nom des données de types différents, ce qui prépare les listes chaînées.

Objectifs

  • Écrire une fonction qui modifie une variable de l'appelant.

  • Définir une structure, accéder à ses champs avec . et ->, et nommer son type avec typedef.

Les pointeurs notes « Cours 3 »

Toute variable occupe une place dans la mémoire, repérée par un numéro : son adresse. Un pointeur permet de manipuler cette adresse, et donc d'atteindre la variable sans la nommer.

Définition Pointeur

Un pointeur est une variable qui contient une adresse mémoire.

Ajout On déclare un pointeur sur un type donné : int *p; déclare p, pointeur sur un int. Deux opérateurs servent à le manipuler :

  • &x donne l'adresse de la variable x ;
  • *p désigne la variable dont p contient l'adresse (on dit qu'on déréférence p).

Exemple Modifier x par un pointeur Ajout

int x = 5;
int *p = &x;      /* p contient l'adresse de x : on dit que p pointe sur x */
*p = 8;           /* range 8 là où pointe p, c'est-à-dire dans x */
printf("%d %d\n", x, *p);   /* 8 8 */

Complément Le pointeur NULL

La constante NULL (de <stdlib.h> ou <stdio.h>) est une adresse qui ne désigne rien. On l'emploie pour dire « pas d'objet », et une fonction qui renvoie un pointeur la renvoie en cas d'échec (c'est le cas de malloc). Déréférencer NULL, ou un pointeur jamais initialisé, arrête le programme (segmentation fault) dans le meilleur des cas.

Attention L'étoile a deux sens Ajout

Dans une déclaration, int *p dit que p est un pointeur. Dans une expression, *p déréférence. Et int *p, q; déclare un pointeur p et un entier q : l'étoile ne porte que sur le nom qui la suit.

Modifier une variable dans une fonction

Complément Le passage par adresse

Le cours 2 a montré qu'une fonction reçoit une copie de ses arguments. Pour qu'elle modifie une variable de l'appelant, on lui passe l'adresse de cette variable, et elle travaille sur *p. L'exemple classique échange deux entiers :

void echange(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}

int x = 1, y = 2;
echange(&x, &y);
printf("%d %d\n", x, y);   /* 2 1 */

C'est ce que fait scanf("%d", &n) : elle reçoit l'adresse de n et y range le nombre lu. Le même mécanisme permet à une fonction de rendre plusieurs résultats.

Tableaux et chaînes de caractères ajout · TD 6

Les notes ne parlent pas des tableaux, mais les chaînes du TD 6 en sont, et leur lien avec les pointeurs est à la base de l'allocation dynamique. Toute cette partie est donc ajoutée.

Tableaux et pointeurs

Complément Un tableau est une suite de cases contiguës

int t[5] = {10, 20, 30, 40, 50}; réserve 5 entiers côte à côte, indicés de 0 à 4. La taille doit être connue à la compilation, d'où les #define N 90 des TP. Dans une expression, le nom du tableau vaut l'adresse de sa première case : t équivaut à &t[0].

Si p pointe sur une case, p + i pointe i cases plus loin (et non i octets), d'où l'équivalence fondamentale :

\[ \texttt{t[i]} \;\equiv\; \texttt{*(t + i)} \]
int *q = t;
printf("%d %d %d\n", *(q + 2), q[3], *t);   /* 30 40 10 */

Attention Un tableau passé à une fonction Ajout

Une fonction qui reçoit un tableau reçoit en fait l'adresse de sa première case : void f(int t[]) et void f(int *t) sont équivalents. Elle peut donc modifier les cases du tableau de l'appelant, mais elle ne connaît pas sa taille (sizeof t y vaut 8, la taille d'un pointeur) : on la passe en paramètre, ou on s'arrête sur une sentinelle, comme le '\0' des chaînes. Le C ne vérifie jamais les indices : écrire dans t[5] écrase ce qui suit le tableau.

Les chaînes de caractères

Complément Un tableau de char terminé par '\0'

Une chaîne est un tableau de char dont la fin est marquée par le caractère nul (cours 1). Une fonction qui traite une chaîne reçoit donc un char * et avance jusqu'au '\0' :

int longueur(const char *s)       /* comme strlen */
{
    int n = 0;
    while (s[n] != '\0')
        n++;
    return n;
}

void minuscules(char *s)          /* modifie la chaîne sur place */
{
    for (int i = 0; s[i] != '\0'; i++)
        if (s[i] >= 'A' && s[i] <= 'Z')
            s[i] += 'a' - 'A';
}

char s[] = "Bonjour LE Monde";
minuscules(s);
printf("%s %d\n", s, longueur(s));   /* bonjour le monde 16 */

const char *s promet que la fonction ne modifiera pas la chaîne. La bibliothèque <string.h> fournit strlen, strcpy(dest, src), strcat(dest, src) et strcmp(s1, s2) (qui vaut 0 si les chaînes sont égales). strcpy et strcat supposent que dest est assez grand, '\0' compris.

Attention Les erreurs du TD 6 Ajout

Les brouillons du TD 6 (TD/TD6/exo1.txt à exo7.txt) réunissent les erreurs les plus fréquentes sur les chaînes :

  • int strlen(char c) : le paramètre est un caractère ; une chaîne se passe par char *c (ou char c[]).
  • c[i] != "\0" compare un caractère à l'adresse d'une chaîne ; on écrit c[i] != '\0', avec des apostrophes. De même s[i] >= 'A' et non "A".
  • scanf("%c", &c) ne lit qu'un caractère. Une chaîne se lit avec scanf("%999s", c) : sans &, puisque c est déjà une adresse, et avec une largeur pour ne pas déborder du tableau.
  • c[i] >= 'A' || c[i] <= 'Z' est toujours vrai : il faut &&.
  • Renvoyer un tableau local (char t[n]; … return t;) rend une adresse qui ne vaut plus rien après le retour : on modifie la chaîne reçue, ou on alloue le résultat avec malloc.
  • Nommer ses fonctions strlen, strcat ou atoi entre en conflit avec la bibliothèque : on choisit ma_strlen, ou un nom français.

L'allocation dynamique notes « allocation dynamique », début

Un tableau déclaré a une taille fixée à la compilation. Quand la taille n'est connue qu'à l'exécution (le nombre d'éléments est saisi, un mot est lu), on demande la mémoire au système pendant que le programme tourne.

Réserver : malloc

Définition malloc

malloc est une fonction qui permet d'allouer dynamiquement de la mémoire pour le programme.

Ajout Déclarée dans <stdlib.h>, malloc(n) réserve n octets et renvoie l'adresse du premier, ou NULL si la mémoire manque. On range cette adresse dans un pointeur et on l'utilise comme un tableau.

int n;
scanf("%d", &n);
int *tab = malloc(n * sizeof(int));   /* n entiers */
if (tab == NULL) {
    fprintf(stderr, "Plus de mémoire\n");
    exit(1);
}
for (int i = 0; i < n; i++)
    tab[i] = i * i;

sizeof

Les notes précisent que sizeof n'est pas une fonction, et l'appellent une « instruction ».

Remarque sizeof est un opérateur À vérifier

Le terme exact est opérateur : sizeof s'emploie dans une expression et donne une valeur, la taille en octets d'un type ou d'une expression, calculée à la compilation. Ce n'est donc pas une instruction (il ne termine rien par un point-virgule) ni une fonction (rien n'est appelé à l'exécution, et les parenthèses ne sont obligatoires qu'autour d'un nom de type : sizeof(int), mais sizeof x). L'idée des notes est juste : sizeof n'est pas une fonction.

Astuce Écrire la taille à partir du pointeur Ajout

int *tab = malloc(n * sizeof *tab); reste juste si l'on change plus tard le type de tab : sizeof *tab est la taille d'une case, quelle qu'elle soit. Pour une chaîne de n lettres, on n'oublie pas la place du '\0' : malloc(strlen(s) + 1).

Codes de retour et exit

Les notes insistent sur la documentation des codes d'erreur. Quand on fait un return dans le main, le code renvoyé en sortie peut être intéressant à gérer selon ce qui s'est passé et la façon dont le programme s'est terminé. Il faut donc une documentation qui permette de le comprendre.

Pour sortir d'un programme depuis n'importe quelle fonction, on utilise exit(), avec en paramètre le code renvoyé en sortie.

Complément Conventions

Par convention, 0 signifie que tout s'est bien passé, une autre valeur signale une erreur ; <stdlib.h> définit EXIT_SUCCESS et EXIT_FAILURE. return 3; dans main et exit(3); n'importe où ont le même effet. Le shell lit ce code dans $? :

$ ./prog fichier_absent.txt
Erreur : fichier introuvable
$ echo $?
2

Documenter, c'est par exemple écrire en tête du programme : « 0 : succès ; 1 : mémoire insuffisante ; 2 : fichier introuvable ». Un script qui lance le programme peut alors réagir à chaque cas.

Libérer : free

La fonction free permet de libérer de l'espace mémoire. Pour éviter les problèmes de double désallocation, on remet le pointeur à NULL une fois la zone libérée.

free(chaine);
chaine = NULL;

Remarque La syntaxe des notes À vérifier

Les notes écrivent free chaine; : free est une fonction, qui s'appelle avec des parenthèses, free(chaine);. Elles parlent aussi de « vider le contenu de chaine » : free ne vide pas la zone, elle la rend au système, et c'est le pointeur que l'on met à NULL, la zone n'existant plus.

Complément Pourquoi remettre à NULL

Après free(p), p contient toujours l'ancienne adresse : c'est un pointeur pendant (dangling pointer). Le libérer une seconde fois, ou s'en servir, a un comportement indéfini, souvent un plantage plus loin, difficile à relier à sa cause. En revanche, free(NULL) ne fait rien : une fois p remis à NULL, un second free(p) est sans danger, et un test if (p != NULL) dit si la zone existe encore.

Attention La fuite de mémoire Ajout

Chaque malloc doit avoir son free. Perdre la dernière adresse d'une zone allouée (en réaffectant le pointeur, ou en quittant la fonction qui la détenait) la rend impossible à libérer : c'est une fuite de mémoire. Sous Linux, valgrind ./prog les détecte. On ne libère que ce qui vient de malloc, jamais un tableau déclaré.

Complément calloc et realloc

calloc(n, taille) réserve n cases et les met à zéro. realloc(p, nouvelle_taille) agrandit ou réduit une zone déjà allouée, en la déplaçant si besoin : on récupère toujours son résultat, p = realloc(p, …), après avoir vérifié qu'il n'est pas NULL.

Les structures notes « allocation dynamique », fin

Un tableau regroupe des données du même type. Pour décrire une personne (un nom, un âge, une taille), il faut regrouper des données de types différents : c'est le rôle des structures.

Définition Structure

Une structure permet de stocker ensemble des données qui n'ont pas le même type. C'est comme une variable qui contient plusieurs variables, appelées champs.

On peut déclarer directement des variables d'une structure sans nom :

struct {
    char *nom;
    int age;
    float taille;
} p1, p2;

Mais on doit identifier les structures en nommant des modèles de structure :

struct personne {
    char *nom;
    int age;
    float taille;
} p3;

Ici, personne est un identificateur. Il crée en réalité une sorte de nouveau type de variable, qui comporte plusieurs champs à la fois. Ajout Le type s'appelle struct personne : on peut ensuite déclarer d'autres variables avec struct personne p4, p5;. Sans nom de modèle, comme pour p1 et p2, on ne pourrait plus déclarer de variable du même type ailleurs, ni passer ces variables à une fonction.

Accéder à un champ

Pour accéder à un champ, on écrit le nom de la variable, un point, puis le nom du champ. Cette syntaxe se compose : si un champ est lui-même une structure, on enchaîne les points.

struct date {
    int jour, mois, annee;
};

struct personne {
    char *nom;
    int age;
    struct date naissance;     /* un champ structure */
};

struct personne p3;
p3.nom = "Richard";
p3.age = 40;
p3.naissance.annee = 1985;     /* les points s'enchaînent */

Remarque Les exemples des notes À vérifier

Les notes écrivent personne.nom = "Richard"; et personne.date.naissance. Or personne est le nom du modèle, pas une variable : le point s'applique à une variable, ici p3.nom. Le second exemple suppose une structure imbriquée ; il est corrigé ci-dessus en p3.naissance.annee, le champ naissance étant de type struct date. L'affectation p3.nom = "Richard" fait pointer nom sur une chaîne constante : on peut la lire, pas la modifier ; pour un nom saisi, on alloue une copie avec malloc.

Complément Initialiser, copier, comparer

Une structure s'initialise à la déclaration, dans l'ordre des champs : struct date d = {14, 7, 1789};. L'affectation p4 = p3; copie tous les champs d'un coup (mais pour nom, c'est l'adresse qui est copiée, pas la chaîne). En revanche, p3 == p4 n'existe pas : on compare champ par champ.

Nommer un type : typedef

Complément Éviter de répéter struct

typedef donne un nouveau nom à un type existant. Les TP s'en servent pour leurs structures : le TP noté de la fourmi de Langton déclare

typedef struct {
    int x;
    int y;
    t_direction dir;
} t_fourmi;

t_fourmi f = {30, 40, nord};   /* plus besoin d'écrire struct */

Les préfixes t_ ou suffixes _t sont des conventions pour reconnaître un nom de type.

Pointeur sur structure

Complément L'opérateur ->

Passer une structure à une fonction en copie toute la structure, et la fonction ne peut pas modifier l'original. On passe donc souvent son adresse. Pour atteindre un champ à partir d'un pointeur, (*p).age s'abrège en p->age :

void vieillir(struct personne *p)
{
    p->age++;                  /* même chose que (*p).age++ */
}

vieillir(&p3);                 /* p3.age passe de 40 à 41 */

Les parenthèses de (*p).age sont nécessaires, car le point est prioritaire sur l'étoile : *p.age voudrait dire *(p.age).

Complément Structures allouées et structures chaînées

Une structure peut être allouée dynamiquement, et contenir un pointeur vers une autre structure du même type. C'est la base des listes chaînées, que le TP 6 noté manipule à travers des primitives fournies (en_tete, suivant, ajout_droit…) :

typedef struct element {
    char lettre;
    struct element *suivant;   /* NULL pour le dernier */
} element_t;

element_t *e = malloc(sizeof *e);
if (e == NULL)
    exit(EXIT_FAILURE);
e->lettre = 'a';
e->suivant = NULL;
/* … */
free(e);

Le nom struct element est obligatoire ici : à l'intérieur de sa propre définition, le nom défini par typedef n'existe pas encore. Les pointeurs et les structures chaînées sont repris en détail en Algorithmique 3.

Exercices ajout

Exercices proposés, dans l'esprit du TD 6 ; les solutions ne viennent pas de l'enseignant.

Exercice 1 Suivre les pointeurs

Qu'affiche ce fragment ?

int a = 3, b = 7;
int *p = &a, *q = &b;
*p = *q + 1;
p = q;
*p = 0;
printf("%d %d\n", a, b);
Solution proposée

8 0. *p = *q + 1 range 8 dans a ; p = q fait pointer p sur b ; *p = 0 met donc b à 0.

Exercice 2 Inverser une chaîne

Écrire void inverse(char *s), qui retourne la chaîne sur place : "abc" devient "cba".

Indice

Deux indices, l'un au début, l'autre sur le dernier caractère avant '\0', qui se rapprochent en échangeant leurs caractères.

Solution proposée 
void inverse(char *s)
{
    int i = 0, j = 0;
    while (s[j] != '\0')
        j++;
    j--;                        /* dernier caractère */
    while (i < j) {
        char t = s[i];
        s[i] = s[j];
        s[j] = t;
        i++;
        j--;
    }
}

Pas besoin de tableau intermédiaire, ni de renvoyer la chaîne : la fonction modifie celle de l'appelant, dont elle a reçu l'adresse.

Exercice 3 Copier une chaîne

Écrire char *copie(const char *s), qui renvoie une nouvelle chaîne allouée avec malloc, identique à s, ou NULL si la mémoire manque. Qui doit libérer le résultat ?

Solution proposée 
char *copie(const char *s)
{
    char *c = malloc(strlen(s) + 1);   /* + 1 pour '\0' */
    if (c == NULL)
        return NULL;
    strcpy(c, s);
    return c;
}

C'est l'appelant, quand il n'a plus besoin de la copie : free(c); c = NULL;. Contrairement à un tableau local, la zone allouée survit au retour de la fonction.

Exercice 4 Une structure de date

Avec struct date définie plus haut, écrire int avant(struct date d1, struct date d2), qui renvoie 1 si d1 est strictement antérieure à d2, 0 sinon.

Solution proposée 
int avant(struct date d1, struct date d2)
{
    if (d1.annee != d2.annee)
        return d1.annee < d2.annee;
    if (d1.mois != d2.mois)
        return d1.mois < d2.mois;
    return d1.jour < d2.jour;
}

À retenir

L'essentiel

  • Un pointeur est une variable qui contient une adresse ; &x donne l'adresse de x, *p la variable pointée.
  • Pour qu'une fonction modifie une variable de l'appelant, on lui passe son adresse et elle écrit dans *p (comme scanf).
  • Le nom d'un tableau vaut l'adresse de sa première case, et t[i] équivaut à *(t + i) ; une fonction ne connaît pas la taille du tableau reçu.
  • Une chaîne est un tableau de char terminé par '\0' ; on la passe en char * et on compare ses caractères à '\0', pas à "\0".
  • malloc(n) réserve n octets et renvoie NULL en cas d'échec : on teste toujours le résultat.
  • sizeof est un opérateur, évalué à la compilation ; malloc(n * sizeof *p) alloue n cases.
  • Chaque malloc a son free(p), suivi de p = NULL pour éviter la double libération.
  • exit(code) termine le programme ; 0 signale le succès, et les autres codes se documentent.
  • Une structure regroupe des champs de types différents ; on accède à un champ par variable.champ, ou pointeur->champ, et typedef donne un nom court au type.

Auto-évaluation

Après int x = 4; int *p = &x; *p += 1;, que vaut x ?

5 : *p désigne x.

Pourquoi void echange(int a, int b) ne peut-elle pas échanger deux variables ?

Elle reçoit des copies : elle échange ses copies, et les variables de l'appelant restent intactes. Il faut void echange(int *a, int *b) et l'appel echange(&x, &y).

Pourquoi n'écrit-on pas de & dans scanf("%s", mot), avec char mot[50] ?

Le nom du tableau vaut déjà l'adresse de sa première case.

Combien d'octets faut-il allouer pour copier une chaîne de 10 lettres ?

11 : malloc(strlen(s) + 1), pour le '\0'.

Qu'est-ce qu'un pointeur pendant, et comment s'en protège-t-on ?

Un pointeur qui contient encore l'adresse d'une zone libérée. On le remet à NULL juste après free : free(NULL) ne fait rien et le test p != NULL devient fiable.

Avec struct personne p3;, pourquoi personne.age = 20; est-il faux ?

personne est le nom du modèle, pas une variable : on écrit p3.age = 20;.

À quoi équivaut p->nom ?

À (*p).nom : le champ nom de la structure pointée par p.
