Codes d'étalement et codes correcteurs

Un sujet de deux heures en trois exercices : construire la matrice de Hadamard de longueur 8 et étaler les bits de deux utilisateurs, étudier un code linéaire systématique (5, 2) de son système jusqu'à sa probabilité d'erreur, puis chercher l'extension d'une source qui permet un code parfait. Les réponses de ton brouillon y sont déjà reprises.

Objectifs

  • Construire une matrice de Hadamard et étaler les bits de plusieurs utilisateurs.
  • Calculer le signal reçu quand deux utilisateurs émettent ensemble.
  • Écrire le système, la matrice génératrice et la matrice de contrôle d'un code systématique.
  • Trouver le pouvoir correcteur, construire la table de décodage par syndrome et calculer une probabilité d'erreur.
  • Appliquer la condition d'un code parfait.

Notions utilisées

  • Séquences de Walsh-Hadamard, étalement et désétalement
  • Matrice génératrice, matrice de contrôle et syndrome
  • Détecter et corriger, codes parfaits

Objectifs du sujet

Première approche de manipulations de codes correcteurs d'erreurs utilisés dans le domaine des télécommunications.

Code de Hadamard TD, exercice 1

Les lignes d'une matrice de Hadamard sont des séquences orthogonales : chaque utilisateur étale ses bits avec la sienne, et le récepteur sépare les utilisateurs qui émettent en même temps.

Exercice 1 Q-1

Donner la matrice de Hadamard de longueur 8.

Indice

Partir de \(H_0 = [1]\) et doubler trois fois : à chaque étape, recopier la matrice à droite et en dessous, et l'inverser en bas à droite.

Exercice 1 Q-2

Un utilisateur 1 (U1) utilise la séquence 2 et émet la séquence 1 0 1. Un utilisateur 2 (U2) utilise la séquence 4 et émet la séquence 0 1 1. Donner le codage de chaque séquence.

Exercice 1 Q-3

Les utilisateurs émettent en même temps. Donner la valeur de la séquence du signal (opération d'étalement).

Génération d'un code correcteur d'erreurs TD, exercice 2

Un code en bloc linéaire se décrit par un système d'équations, puis par deux matrices : la matrice génératrice, qui code, et la matrice de contrôle, qui calcule le syndrome.

Exercice 2 Le code

Un code associe à deux éléments binaires d'information des mots constitués de cinq éléments binaires suivant la correspondance :

Éléments binaires d'informationMots code
0000000
0101101
1010111
1111010

Exercice 2 Q-1

Le code est linéaire systématique. Expliquez l'implication de ce type de code.

Exercice 2 Q-2

Expliciter le code sous forme d'un système.

Exercice 2 Q-3

Donner l'expression de la matrice génératrice et de la matrice de contrôle.

Exercice 2 Q-4

Préciser le pouvoir correcteur de ce code en tenant compte de la question précédente.

Exercice 2 Q-5

Construire une table de décodage indiquant les configurations d'erreurs effectivement corrigées.

Indice

Le syndrome d'une erreur simple est la ligne de \(H\) de l'élément touché. Combien de syndromes différents peut-on obtenir avec 3 éléments de contrôle ? Les erreurs simples les prennent-elles tous ?

Exercice 2 Q-6

On suppose que les éléments binaires du code sont transmis sur un canal binaire symétrique de probabilité d'erreur inférieure à 0,04. Donner la probabilité d'erreur de notre code.

Extension d'un code correcteur TD, exercice 3

Un code parfait n'existe que pour certaines longueurs : en regroupant plusieurs messages de la source (son extension), on peut atteindre l'une d'elles.

Exercice 3 Q-1

La longueur du message de la source est 3. On envisage d'utiliser un code correcteur d'erreurs linéaire parfait de distance minimum 3 sur un canal binaire symétrique. Quel doit être l'ordre minimum e d'extension de la source pour que la construction d'un tel code soit possible ?

Indice

L'extension d'ordre \(e\) donne des messages de \(3e\) éléments. Un code parfait qui corrige une erreur vérifie \(2^k = 1 + n\), avec \(n = 3e + k\).

Exercice 3 Q-2

En utilisant le code trouvé en Q-1, calculer la probabilité pour qu'un mot de l'extension d'ordre e soit correctement transmis.

À retenir

Les méthodes

  • Hadamard : \(H_n = \begin{bmatrix} H_{n-1} & H_{n-1} \\ H_{n-1} & -H_{n-1} \end{bmatrix}\) ; chaque ligne est la séquence d'un utilisateur. Un bit 1 émet la séquence, un bit 0 son opposée ; les signaux des utilisateurs s'additionnent.
  • Code systématique \((n, m)\) : l'information en tête, \(G = \begin{pmatrix} I_m \\ P \end{pmatrix}\), \(H = \begin{pmatrix} P^T \\ I_k \end{pmatrix}\) en binaire, et \(H^T c = 0\) pour tout mot de code.
  • Code linéaire : \(d_{min}\) = plus petit poids d'un mot non nul ; il détecte \(d_{min} - 1\) erreurs et en corrige \(\lfloor (d_{min} - 1) / 2 \rfloor\).
  • Table de décodage : \(2^k\) syndromes, chacun associé à l'erreur de plus faible poids qui le produit ; la probabilité de bien décoder est la somme des probabilités de ces erreurs.
  • Code parfait corrigeant une erreur : \(2^k = 1 + n\) (codes de Hamming \(n = 2^k - 1\)).

Auto-évaluation

Combien d'utilisateurs une matrice de Hadamard de longueur 16 peut-elle servir en même temps ?

16 : une séquence orthogonale par ligne, et pas une de plus.

Un code linéaire a pour mots non nuls de poids minimal 4. Que détecte-t-il, que corrige-t-il ?

Il détecte 3 erreurs et en corrige 1.

Pourquoi le syndrome ne dépend-il que de l'erreur ?

Parce que \(H^T (c + e) = H^T c + H^T e = H^T e\), puisque \(H^T c = 0\) pour tout mot de code.

Quel est le plus petit code de Hamming qui protège des messages de 4 bits ?

Le code (7, 4) : \(k = 3\), \(2^3 = 1 + 7\).
