Introduction à la POO

Quatre sujets pour concevoir des classes : le décaleur d'un afficheur lumineux, une file circulaire chaînée, un compte en banque avec un seuil de retrait, et le crible d'Ératosthène bâti sur une chaîne de filtres. Pour chacun, les classes se dessinent dans un diagramme et le code s'écrit dans un éditeur Ruby ; les réponses de ton brouillon y sont déjà reprises.

Simulation d'afficheurs lumineux TD, TD1-sujet 3

TD1-Sujet 3 Simulation d'afficheurs lumineux – Partie 1

Le but de cet exercice est de simuler en Ruby les afficheurs lumineux qui font circuler un texte en boucle.

A) Le décaleur. Intéressons-nous d'abord au décaleur. C'est un objet qui stocke une suite de l caractères (avec l > 0). l est constant et est appelé largeur du décaleur. Initialement, un décaleur contient l espaces. Les quatre fonctionnalités d'un décaleur sont :

  • fournir un accès à la largeur du décaleur ;
  • remettre à zéro : force tous les caractères à espace ;
  • décaler d'une position vers la gauche sa suite de caractères : le caractère le plus à gauche est supprimé de la suite et est renvoyé par la méthode. Le nouveau caractère le plus à droite est fixé à la valeur du paramètre fourni ;
  • l'affichage d'un décaleur affiche le contenu de celui-ci.

Définir entièrement en Ruby la classe Decaleur. Écrire en Ruby le code de toutes les méthodes de la classe, sans oublier en particulier les méthodes de création/initialisation.

Exemple d'utilisation de la classe Decaleur

Un tableau de l caractères suffit : shift enlève et rend le premier élément, push ajoute à la fin. Les tirets de l'exemple représentent des espaces.

Un TDA file circulaire TD, TD1-sujet 4

TD1-Sujet 4 Un TDA File circulaire en Ruby

On souhaite réaliser le type de données abstrait (TDA) File par chaînage circulaire en Ruby. On rappelle qu'une file est une liste de type FIFO (First In First Out) : une file est une liste où les insertions s'effectuent à la fin et les suppressions au début.

Les opérations primitives autorisées sur une liste sont au nombre de 5 : faire entrer un élément dans la file, faire sortir un élément de la file, tester si la file est vide, accéder au premier élément de la file, afficher le contenu de la file.

  • Une file est représentée par une cellule d'en-tête dont le champ suivant pointe sur la dernière cellule de la file ; le champ suivant de cette dernière pointe sur la première.
  • Exemple : représentation de la file 1, 2, 3, 4.
  • Avantage de cette réalisation pour les File : toutes les opérations (sauf détruire) sont en O(1).
  1. Déterminer les objets nécessaires à la réalisation d'une file circulaire.
  2. Coder en Ruby la/les classes nécessaires.

Écrire un programme de test, qui crée la file (m,e,r,c,i, ,J,a,c,o) et l'affiche.

Remarque Le sujet du TD 1

Au TD 1, ce sujet demandait aussi une sixième primitive, calculer la taille de la file, et le diagramme de classes ; la solution donne les deux.

La classe Compte, un peu moins rudimentaire TD, sujet 1

Sujet 1 La classe Compte

La classe Compte du cours n° 1 d'introduction à Ruby, un peu moins rudimentaire, avec un seuil de retrait et des fonctions d'accès générées par le « Coding Assistant ». Les objets de cette classe :

  1. sont caractérisés par leur numéro, leur titulaire et leur solde ;
  2. sont capables de donner leur solde, de déposer une somme et de retirer une somme si le seuil de retrait n'est pas atteint.
    1. Par défaut, le seuil est fixé à 0.
    2. La notion de seuil sera implémentée en définissant une méthode privée qui renvoie la valeur du seuil autorisé. (On aurait aussi pu utiliser une variable d'instance.)
  3. Pour créer un objet de cette classe, on envoie le message ouvrir à la classe Compte avec pour arguments le numéro, le titulaire et le solde du compte que l'on veut créer. Il n'est pas possible de modifier les informations du compte (titulaire et numéro). Le solde ne peut être modifié que par les opérations de retrait et de dépôt prévues à l'interface.
  4. Faire le nécessaire pour pouvoir afficher un Compte avec les instructions classiques du système (puts, print, etc.).

Le crible d'Ératosthène TD, sujet 2

Sujet 2 Le crible d'Ératosthène

Donner une réalisation en Ruby du crible d'Ératosthène, un algorithme qui permet de trouver l'ensemble des nombres premiers inférieurs ou égaux à n, n étant donné.

Principe : un générateur envoie des nombres de 2 à n de façon incrémentale. Une série de filtres sont placés de façon à récupérer les valeurs envoyées par les filtres précédents. Lorsqu'un nombre x est récupéré par un filtre i, si x est divisible par i, alors x n'est pas premier. Sinon x passe sur le filtre suivant. Si x n'a rencontré aucun diviseur à la sortie de la chaîne des filtres, on construit au bout de la chaîne un filtre de valeur x.

  1. Donner une description en français des classes nécessaires à la réalisation de ce programme.
  2. Écrire en Ruby la définition des classes correspondantes.
  3. Écrire en Ruby un programme de test demandant un nombre à l'utilisateur et affichant tous les nombres premiers inférieurs à ce nombre.

À retenir

Les méthodes

  • Concevoir d'abord : quelles classes, quels attributs (privés), quelle interface (méthodes publiques) ; le diagramme de classes le résume.
  • Un nom de classe commence par une majuscule ; attention aux classes qui existent déjà en Ruby (File).
  • Une structure chaînée se fait avec des objets qui se désignent (une cellule, sa suivante) ; on garde un accès direct aux cellules dont les opérations ont besoin.
  • private cache une règle (le seuil) que les sous-classes pourront redéfinir ; to_s rend un objet affichable par puts.

Auto-évaluation

Que rend [1, 2, 3].shift, et que devient le tableau ?

1 ; le tableau devient [2, 3].

Dans une file circulaire, pourquoi l'en-tête désigne-t-il la dernière cellule plutôt que la première ?

Parce que la dernière donne accès aux deux bouts : on entre après elle, et sa suivante est la première, d'où l'on sort. Toutes deux en O(1).

Pourquoi le seuil du compte est-il une méthode privée plutôt qu'une constante ?

Une sous-classe pourra la redéfinir (un compte avec découvert autorisé) sans toucher à retirer.

Que doit définir une classe pour que puts objet affiche quelque chose de lisible ?

Une méthode to_s, que puts appelle.
