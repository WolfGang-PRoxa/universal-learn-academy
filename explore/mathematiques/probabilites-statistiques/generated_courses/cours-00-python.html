Le langage Python diapos 1–15

Avant d'écrire du code, il faut savoir comment Python l'exécute, et sous quelles formes on peut lui en donner. Le plan des diapos annonce neuf parties ; les six premières sont traitées, les dictionnaires, les expressions régulières et les fichiers sont seulement listés.

Principales caractéristiques

  • Python est un langage de programmation inventé en 1991 par Guido van Rossum ; il est interprété, multiplateforme et multiparadigme (impératif, objet, fonctionnel), à la fois simple et puissant.
  • Son typage est dynamique et fort (dynamic, strong typing), avec un ramasse-miettes (garbage collector) qui libère la mémoire.
  • On peut travailler en interactif ; le langage est libre (open source) ; il fournit des types de données structurés (tuples, ensembles, listes, dictionnaires), un système de gestion des exceptions et de très nombreuses bibliothèques.
  • Python est utilisé partout (NASA, GAFA, Dropbox, Instagram, IBM) : applications web (Django, Flask), applications de bureau, serveurs réseau, apprentissage automatique (pandas, scikit-learn), médias… Les diapos 7 et 8 le montrent parmi les langages les mieux payés aux États-Unis et les plus utilisés sur GitHub.

Compiler, interpréter

Compilation diapo 9

Le source est traduit en langage objet en au moins quatre phases : trois phases d'analyse (lexicale, syntaxique, sémantique), une phase de production de code objet, puis l'édition de liens. La compilation est contraignante, mais elle offre au final une grande vitesse d'exécution.

Interprétation diapo 10

Chaque ligne du source est analysée et traduite au fur et à mesure en instructions ; aucun programme objet n'est généré. La technique est très souple, mais le code produit est peu performant.

Python utilise une technique mixte, l'interprétation du bytecode compilé : le source est d'abord compilé en une forme intermédiaire, le bytecode, qu'une machine virtuelle interprète. C'est un bon compromis entre la facilité de développement et la rapidité d'exécution, et le bytecode est portable sur tout ordinateur muni de la machine virtuelle Python diapo 11.

Trois façons d'exécuter du Python

  • Mode interactif diapo 12 : on tape python dans un terminal, puis une ligne après l'autre ; la réponse s'affiche après chaque retour chariot. C'est un bon test pour vérifier que Python est bien installé. On quitte avec exit() ou quit().
  • Mode script diapo 13 : la plupart des programmes sont beaucoup plus longs ; on les écrit dans un fichier, que Python exécute. Par convention, ce fichier a le suffixe .py, et peut commencer par # coding: utf-8.
  • Jupyter notebook diapo 14 : un document qui mêle du texte en Markdown et des cellules de code Python, très utilisé en science des données pour explorer et analyser des données. C'est le format des TP de ce module.
$ python
>>> x = 1
>>> print(x)
1
>>> x = x + 1
>>> print(x)
2
>>> exit()

Constantes, variables, types, expressions diapos 16–31

Un programme est fait de mots (variables, mots réservés), assemblés en phrases qui respectent la syntaxe, pour raconter une « histoire » : un traitement qui a un but. Tout usage illégal d'un mot réservé, ou toute formulation qui ne respecte pas la syntaxe de Python, provoque une SyntaxError.

Identifiants et mots réservés

Il faut une politique cohérente de nommage des identifiants diapo 17 : UPPER_CASE pour les constantes, TitleCase pour les classes, camelCase pour les fonctions, les méthodes et les interfaces graphiques, lower_case pour tous les autres identifiants.

NB_ITEMS = 12             # UPPER_CASE
class MaClasse: pass      # TitleCase
def maFonction(): pass    # camelCase
mon_id = 5                # lower_case

Les mots réservés ne peuvent pas servir d'identifiants. Le module keyword les liste diapo 18 :

import keyword
for e in (keyword.kwlist):
    print(e, end="\t")

On obtient 35 mots en Python 3.11 : False None True and as assert async await break class continue def del elif else except finally for from global if import in is lambda nonlocal not or pass raise return try while with yield.

Une instruction d'affectation (x = 2) donne une valeur à une variable ; on peut affecter une expression (x = x + 2), et afficher avec print(x). Une expression combine des variables, des opérateurs, des constantes et des appels de fonctions diapo 19.

Règle Priorité des opérateurs diapos 21–22

  1. parenthèses ;

Types et conversions

En Python, les constantes littérales et les variables sont typées diapo 23. Python distingue un entier d'une chaîne, et c'est ce qui donne leur sens aux opérateurs : + signifie « addition » pour les nombres et « concaténation » pour les chaînes, * « multiplication » pour les nombres et « concaténation multiple » pour les chaînes.

v1 = 1 + 4
print(v1)                  # 5
v2 = 'hello ' + 'there'
print(v2)                  # hello there
v3 = 'abc' * 5
print(v3)                  # abcabcabcabcabc

Quand une expression mêle entiers et nombres à virgule flottante, les entiers sont implicitement convertis en float : le type float est « contaminant ». On peut aussi forcer une conversion avec int() et float() ; type() donne le type d'une valeur diapo 24.

print(2 * 2.5)       # 5.0
n = 42
print(type(n))       # <class 'int'>
f = float(n)
print(f, type(f))    # 42.0 <class 'float'>
i = int(f)
print(i, type(i))    # 42 <class 'int'>

Entrées-sorties

La fonction input() bloque le déroulement du programme et attend une saisie au clavier ; elle retourne une chaîne de caractères. La fonction print() affiche des données (constantes, variables, expressions) séparées par des virgules, chaque virgule donnant une espace diapo 28. Pour lire un nombre, il faut convertir la chaîne diapo 30 :

an_cour = 2020
an_nais = input('Année de naissance :')    # saisie : 1983
age = an_cour - int(an_nais)
print('Vous avez', age, 'ans')             # Vous avez 37 ans

L'opérateur % formate une chaîne : chaîne à formater % variable, expression ou tuple, avec %s pour une chaîne, %i pour un entier, %.2f pour un flottant à deux décimales diapo 29.

prenom = 'Jérôme'
print('Bonjour %s' % prenom)              # Bonjour Jérôme
v2 = 745.8183
print('Résultat = %.2f' % v2)             # Résultat = 745.82 (arrondi)
num, rue, pos, vil = 13, 'avenue René Laennec', 72000, 'Le Mans'
adr = '%i %s %i %s' % (num, rue, pos, vil)
print(adr)                                # 13 avenue René Laennec 72000 Le Mans
print(f'Résultat = {v2:.2f}')             # même chose avec une f-string

Ajout La dernière ligne utilise une f-string (Python 3.6 et plus), la forme la plus courante aujourd'hui : les expressions entre accolades sont évaluées, et :.2f fixe le format.

Tout ce qui suit #, ou se trouve entre ''' et ''', est ignoré par Python (enfin, presque : une chaîne entre triples guillemets en tête de fonction en devient la documentation). Les commentaires servent à expliquer une portion de code, à documenter qui l'a écrit, ou à désactiver temporairement une ligne diapo 31.

Conditions et exceptions diapos 32–41

Un programme doit pouvoir choisir ce qu'il fait selon les données, et réagir proprement quand une donnée est invalide.

Étapes conditionnelles

x = 5
if x < 10:
    print('Smaller')
if x > 20:
    print('Bigger')
print('OK')
# Affiche : Smaller, puis OK

Les expressions booléennes contrôlent le déroulement du programme. Elles utilisent les opérateurs de comparaison <, <=, ==, >=, >, != (différent) et l'opérateur unaire not, et valent vrai ou faux. Les opérateurs de comparaison examinent les variables mais ne les modifient pas diapo 34.

Attention = et ==

= affecte une valeur, == compare. if x = 5: est une SyntaxError.

Règles Indentation diapo 35

  • On augmente l'indentation après le mot-clé if (et ses :) pour ouvrir le bloc ; on la maintient pour indiquer la portée du bloc ; on la ramène au niveau du if pour fermer le bloc.
  • Les lignes vides sont ignorées : elles n'affectent pas l'indentation.
  • Ne jamais mélanger tabulations et espaces : on obtient des IndentationError même si tout paraît normal. La plupart des éditeurs transforment les tabulations en espaces (dans Notepad++ : Settings › Preferences › Language, Tab Settings).

Dans une suite de elif, seule la première condition vraie compte.

Gestion des exceptions

Certaines erreurs ne peuvent pas être évitées : si l'utilisateur tape SALUT au lieu d'une année, int() lève une ValueError et le programme s'arrête. On les appelle des exceptions (exceptions) diapo 40.

On peut les anticiper et les gérer avec la structure try / except. Il faut identifier la portion de code où l'exception peut être levée, écrire le traitement normal (s'il n'y a pas d'exception) et le traitement exceptionnel diapo 41.

ANNEE = 2020
try:
    naissance = int(input('Année de naissance :'))
except:
    print("Erreur: vous n'avez pas saisi une année")
    exit()
age = ANNEE - naissance
print('Vous avez %i ans' % age)

Astuce Nommer l'exception attendue

Ajout Un except: seul attrape tout, y compris une faute de frappe dans le nom d'une variable. On préfère écrire except ValueError:, l'exception que lève int().

Boucles et listes diapos 42–54

Répéter une opération, et ranger plusieurs valeurs dans une même structure, sont les deux besoins de base d'une simulation : générer \(N\) tirages, puis calculer leur fréquence.

La boucle while

n = 5
while n > 0:
    print(n)
    n = n - 1
print('FEU')
# Affiche 5 4 3 2 1 (une valeur par ligne), puis FEU

Tant que la condition est vraie, le bloc est répété. Si rien ne la rend fausse, la boucle ne s'arrête jamais diapo 44 :

n = 5
while n > 0:          # n n'est jamais modifié : boucle infinie
    print('Laver')
    print('Rincer')
print('Sécher')       # jamais atteint

Le type liste

La liste (list) est un type structuré, une structure de données linéaire et ordonnée, composée de valeurs quelconques (entiers, flottants, chaînes…), éventuellement hétérogènes. Ses éléments sont séparés par des virgules, entre crochets diapo 45.

lst = [1, 2, 3, 'hello', 3.14]
print(len(lst))      # 5
print(lst[0])        # 1  : l'index du premier élément est 0
print(lst[3])        # hello
lst[3] = 'bonjour'   # modifier un élément
del lst[4]           # supprimer (attention : pas de parenthèses)
lst.append(9999)     # ajouter à la fin : méthode de l'objet liste
print(lst)           # [1, 2, 3, 'bonjour', 9999]

Accéder, modifier ou supprimer un élément qui n'existe pas (lst[5] sur une liste de 5 éléments) lève une IndexError: list index out of range diapos 46–48. La syntaxe lst.append(…) est l'appel d'une méthode : en Python, les listes sont des objets à part entière diapo 49.

Une liste pouvant contenir des valeurs de n'importe quel type, elle peut contenir des listes : on obtient une structure à deux entrées diapo 50.

lst = [[1, 2, 3], [4, 5, 6]]
print(lst[0])        # [1, 2, 3]
print(lst[0][1])     # 2
lst.append([7, 8, 9])
print(lst)           # [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

La boucle for

Une boucle for parcourt une liste et exécute un bloc pour chacun de ses éléments. Si la liste est vide, le bloc est sauté ; sinon, il est répété autant de fois qu'il y a d'éléments. Contrairement à la boucle while, la boucle for s'arrête à coup sûr diapos 51–52.

for element in [1, 2, 3, 'hello', 3.14]:
    print('bonjour', element)     # bonjour 1, bonjour 2, …, bonjour 3.14

Pour faire varier i de 1 à 1000, on peut utiliser une boucle while avec une variable d'itération, ou une boucle for sur range(1, 1001) : la borne inférieure est incluse, la borne supérieure exclue diapo 53.

i = 1
while i < 1001:
    print(i)
    i = i + 1
for i in range(1, 1001):
    print(i)

Méthode while ou for ? diapo 54

  • Quand on connaît à l'avance le nombre d'éléments sur lesquels on itère : boucle for.
  • Quand on ne le connaît pas : boucle while.
  • Tout ce que fait une boucle for peut s'écrire avec while, de façon un peu plus « verbeuse ».

Chaînes de caractères diapos 55–57

Les données des TP arrivent sous forme de texte : savoir découper une chaîne est le premier pas pour les lire.

Le type chaîne (str) représente des séquences de caractères Unicode. C'est un type non modifiable : une chaîne ne peut plus être modifiée une fois créée, et toute transformation produit une nouvelle valeur distincte. On peut voir une chaîne comme une liste de caractères, traitée avec les fonctions communes aux séquences, ou avec des méthodes propres aux chaînes diapo 55.

ch = 'Python 3.5'
print(len(ch))                    # 10
print(ch.upper())                 # PYTHON 3.5
print(ch[0], ch[3], ch[5])        # P h n
print(ch[2:6])                    # thon   (de l'indice 2 inclus à 6 exclu)
print(ch[:6], ch[2:], ch[-1])     # Python thon 3.5 5
print(ch.find('thon'))            # 2      (position de la sous-chaîne)
print(ch.replace('thon', 'tule')) # Pytule 3.5
print(ch.split())                 # ['Python', '3.5']
print('-'.join(['Python', '3.5']))  # Python-3.5
for c in ch:                      # une chaîne est une séquence
    print(c)

Remarque split avec un séparateur

Ajout split() sans argument coupe sur les espaces ; split(';') coupe sur le point-virgule, le séparateur des fichiers CSV des TP 4 et 5. strip() retire les espaces et le saut de ligne aux deux bouts : line.strip().split(';') est la formule des notebooks.

Fonctions diapos 58–75

Une fonction est une « boîte noire » qui reçoit des entrées typées (les arguments) et produit une sortie typée (le résultat), parfois avec des effets de bord. Il n'est pas nécessaire de connaître son code pour l'utiliser : il suffit de savoir comment l'appeler diapo 59.

Fonctions prédéfinies

  • float() prend un entier, un flottant ou une chaîne et rend un flottant ; sin() prend un nombre et rend un flottant ; random() ne prend rien et rend un flottant différent à chaque appel diapo 60.
  • print() et input() ont des effets de bord (side effects) : affichage, saisie. input() rend la chaîne saisie diapo 61.
  • max() est « polymorphe » : sur une chaîne elle rend le plus grand caractère (max('hello world') → 'w', max('Hello World') → 'r', car les majuscules sont avant les minuscules) ; sur plusieurs nombres, le plus grand (max(5, 6, 4) → 6) ; sur un seul nombre, une TypeError: 'int' object is not iterable diapo 62.

Attention au nombre et au type des arguments : float(3), float(3.0) et float('3'), ou max('abc') et max('abc', 'axc'), ne font pas le même traitement sous le même nom diapo 63. La liste des fonctions prédéfinies est sur docs.python.org diapo 64.

Bibliothèques

La plupart des fonctions sont rangées par familles : les fonctions mathématiques dans math, les générateurs aléatoires dans random, les fonctions système dans sys et os. Il faut importer la bibliothèque au début du programme, de l'une de trois façons diapo 65 :

import math
print(math.sin(math.pi / 2))     # 1.0 : on préfixe par le nom du module

from math import pi, sin
print(sin(pi / 2))               # 1.0 : seulement les noms choisis

from math import *
print(sin(pi / 2))               # 1.0 : tout le module (déconseillé : conflits de noms)

Ajout Les notebooks utilisent une quatrième forme, l'alias : import numpy as np, import numpy.random as rdm.

Définir ses fonctions

Si une même portion de code est dupliquée à plusieurs endroits, ou si l'on a écrit un algorithme réutilisable, on a intérêt à définir une nouvelle fonction avec def diapo 66. Un argument est une valeur transmise à la fonction au moment de l'appel ; un paramètre est une variable de la définition, qui prend la valeur de l'argument lors de l'appel diapo 67.

def bonjour(lang):            # lang est un paramètre
    if lang == 'es':
        print('Hola')
    elif lang == 'fr':
        print('Bonjour')
    else:
        print('Hello')

bonjour('fr')                 # 'fr' est un argument : affiche Bonjour
print(lang)                   # NameError: name 'lang' is not defined

La portée d'une variable est la portion de code où elle possède une valeur. Celle d'un paramètre est la définition de la fonction : en dehors, il n'est pas défini, d'où la NameError diapo 68.

Valeurs de retour

Une fonction qui renvoie un résultat dans l'expression appelante comporte le mot-clé return ; le type d'une fonction est celui de la valeur retournée diapo 69. Il peut y avoir plusieurs return : dès qu'un return est exécuté, l'exécution sort de la fonction. Dans l'exemple des mois, une suite de if et une suite de elif sont donc équivalentes diapo 70.

def bonjour():
    return "Hello"

print(bonjour(), "Glenn")     # Hello Glenn

def foobar(a, b):
    x = a + b
    y = a - b
    return (x, y)             # un tuple

(i, j) = foobar(1, 2)
print(i, j)                   # 3 -1

Pour renvoyer plusieurs valeurs, on renvoie un tuple, un groupe de valeurs réunies dans un même objet, que l'on récupère par une affectation multiple diapo 71.

Récursivité

Une fonction récursive s'utilise elle-même pour produire son résultat. Sans cas d'arrêt, la récursion est infinie diapos 72–73 :

def facto_faux(n):
    return n * facto_faux(n - 1)     # facto_faux(3) : RecursionError

def facto(n):
    if n == 0:
        return 1                     # cas sans appel récursif
    else:
        return n * facto(n - 1)

print(facto(3))                      # 6

Il faut toujours identifier un cas (ou plusieurs) sans appel récursif ; sinon l'appel génère une erreur ou un plantage. Les diapos parlent de RuntimeError: maximum recursion depth exceeded ; depuis Python 3.5, l'exception s'appelle RecursionError, une sorte de RuntimeError.

Conseils Organiser son code diapos 74–75

  • Organiser le code en « paragraphes » qui capturent une pensée complète, et les nommer.
  • Si un code fonctionne quelque part, ne pas le répéter : le réutiliser, en en faisant une fonction.
  • Si le code devient trop long ou trop complexe, le séparer en parties logiques, et faire des fonctions de ces morceaux.
  • Construire une bibliothèque des opérations que l'on répète continuellement, et la partager.

Complément Les dictionnaires

Un dictionnaire (dictionary, type dict) associe des valeurs à des clés : on accède à une valeur par sa clé, et non par une position. Les clés sont souvent des chaînes.

effectifs = {'Masculin': 3386, 'Feminin': 3506}
print(effectifs['Feminin'])          # 3506
effectifs['Total'] = 6892            # ajouter (ou remplacer) une entrée
print('Total' in effectifs)          # True : test d'appartenance d'une clé
for cle, valeur in effectifs.items():
    print(cle, valeur)

# Accumuler des listes par clé, comme dans le notebook du TP 4
dic = {}
for h, v in [('altitude', 2768), ('pente', 22), ('altitude', 4108)]:
    if h in dic:
        dic[h].append(v)
    else:
        dic[h] = [v]
print(dic)                           # {'altitude': [2768, 4108], 'pente': [22]}

Complément Lire un fichier texte

open(chemin, 'r') ouvre un fichier en lecture ; dans un bloc with, il est refermé automatiquement à la sortie du bloc. Une boucle for sur le fichier donne une ligne à la fois, saut de ligne compris ; enumerate donne en plus le numéro de la ligne, ce qui permet de traiter la ligne d'en-tête à part.

with open('donnees.csv', 'w') as f:            # on crée un petit fichier
    f.write('x;y\n1;2.5\n2;4.1\n3;6.2\n')

xs, ys = [], []
with open('donnees.csv', 'r') as f:
    for i, line in enumerate(f):
        tab = line.strip().split(';')
        if i == 0:
            headers = tab                         # ['x', 'y']
        else:
            xs.append(int(tab[0]))
            ys.append(float(tab[1]))
print(headers, xs, ys)                            # ['x', 'y'] [1, 2, 3] [2.5, 4.1, 6.2]

Deux pièges vus dans les données des TP : les nombres à virgule décimale française (132,4 dans ressources_eau2018.csv) se convertissent avec float(s.replace(',', '.')) ; un fichier enregistré en UTF-8 avec un en-tête BOM s'ouvre avec open(…, encoding='utf-8-sig'), surtout sous Windows, où l'encodage par défaut n'est pas l'UTF-8.

Vers les TP : numpy, matplotlib, scipy.stats

Les notebooks supposent connues trois bibliothèques « vues au semestre précédent ». Ce rappel en donne l'essentiel pour le module, sans faire les questions des TP.

Complément numpy : calculer sur des tableaux

Un tableau numpy (np.array) applique les opérations à tous ses éléments d'un coup, sans boucle. numpy.random génère des nombres aléatoires.

import numpy as np
import numpy.random as rdm

x = np.array([249, 248, 256, 252, 242])
print(x - 250)                      # [-1 -2  6  2 -8] : opération élément par élément
print(np.mean(x), np.std(x, ddof=1))   # moyenne, écart-type empirique S(n-1)
print(x[x > 250])                   # [256 252] : masque booléen
print(np.linspace(0, 1, 5))         # [0.   0.25 0.5  0.75 1.  ]

rdm.seed(0)                         # pour retrouver les mêmes tirages
u = rdm.random(1000)                # 1000 flottants uniformes dans [0, 1[
print(np.mean(u < 0.3))             # proche de 0.3 : fréquence d'un succès

Complément matplotlib : tracer

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-4, 4, 200)
plt.plot(x, np.exp(-x**2 / 2) / np.sqrt(2 * np.pi), label='densité')
plt.hist(np.random.normal(0, 1, 1000), bins=20, density=True, label='tirages')
plt.bar([0, 1], [0.7, 0.3])          # diagramme en bâtons
plt.title('titre'); plt.xlabel('x'); plt.ylabel('y'); plt.legend()

Dans plt.hist, density=True normalise l'histogramme pour que son aire vaille 1 : on peut alors le comparer à une densité (TP 3).

Complément scipy.stats : les lois du cours

Chaque loi est un objet avec les mêmes méthodes : pmf (loi d'une variable discrète, \(P(X = k)\)), pdf (densité), cdf (fonction de répartition \(P(X \le x)\)), sf (\(P(X \gt x)\)), ppf (réciproque de cdf), mean, var, std, rvs (tirages), interval (intervalle central). Le cours 2 et le cours 3 en donnent des exemples.

from scipy.stats import binom, poisson, norm, expon

print(round(binom.pmf(3, 15, 0.3), 4))   # P(X = 3) pour B(15 ; 0,3) : 0.17
print(round(poisson.cdf(2, 3), 4))       # P(X ≤ 2) pour P(3) : 0.4232
print(round(norm.cdf(1.96), 4))          # 0.975
print(round(norm.ppf(0.975), 2))         # 1.96 : le z_alpha du cours 4
print(expon(scale=1/4).mean())           # 0.25 : E(4) se paramètre par scale = 1/λ

À retenir

L'essentiel

  • Python compile le source en bytecode, interprété par une machine virtuelle ; on l'utilise en interactif, en script .py ou en notebook.
  • Priorités : parenthèses, **, puis * / // %, puis + -, de gauche à droite.
  • / rend toujours un float ; // rend un int si les deux opérandes sont entiers ; le float est contaminant.
  • input() rend une chaîne : la convertir avec int() ou float(), dans un try / except ValueError si la saisie peut être invalide.
  • Le bloc d'un if, d'un while, d'un for ou d'un def est défini par l'indentation ; dans une suite de elif, seule la première condition vraie compte.
  • Listes : indices à partir de 0, append, del, tranches [début:fin] avec fin exclue ; range(a, b) va de \(a\) à \(b - 1\).
  • Les chaînes ne sont pas modifiables ; strip() et split(';') découpent une ligne de CSV.
  • Une fonction rend sa valeur par return (plusieurs valeurs : un tuple) ; ses paramètres n'existent qu'à l'intérieur ; une fonction récursive a toujours un cas d'arrêt.
  • Pour les TP : np.mean, np.std(x, ddof=1), plt.hist(…, density=True), et les méthodes pmf, pdf, cdf, ppf de scipy.stats.

Auto-évaluation

Que vaut 2 + 3 * 4 ** 2 // 10 ?

\(4^2 = 16\), puis \(3 \times 16 = 48\), \(48 // 10 = 4\), enfin \(2 + 4 = 6\).

Qu'affichent print(7 / 2), print(7 // 2) et print(7.0 // 2) ?

3.5, 3 et 3.0.

n = input('n ? ') puis print(n * 2) avec la saisie 21 : qu'affiche-t-on ?

2121 : input rend la chaîne '21', et * sur une chaîne la répète. Il fallait int(input(…)).

Combien de fois s'exécute le corps de for i in range(3, 10, 2): ?

4 fois, pour \(i = 3, 5, 7, 9\) : le troisième argument est le pas, et 10 est exclu.

ch = 'statistiques' : que valent ch[0:4], ch[-3:] et ch.count('t') ?

'stat', 'ues' et 3.

Pourquoi lst[len(lst)] lève-t-il toujours une erreur ?

Les indices vont de 0 à len(lst) - 1 : l'indice len(lst) est en dehors de la liste (IndexError). Le dernier élément est lst[-1].

Que renvoie une fonction qui se termine sans return ?

None. x = print('a') affiche a et met None dans x.

Quelle différence entre np.std(x) et np.std(x, ddof=1) ?

La première divise par \(n\), la seconde par \(n - 1\) : c'est l'écart-type empirique \(S_{n-1}\) du cours 4, dont le carré estime la variance sans biais.
