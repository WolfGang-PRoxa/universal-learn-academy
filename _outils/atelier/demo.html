Démonstration de l'atelier

Chaque éditeur de l'atelier en situation d'exercice, tel qu'il apparaît dans un TD interactif. Le balisage de cette page sert de modèle : on copie un bloc <div class="atelier"> d'ici pour l'adapter.

Mode d'emploi

  • Construire la réponse sur le dessin, ou dans la vue texte (bouton « Les deux »).
  • « Vérifier » contrôle la forme ; « Comparer » mesure l'écart avec la solution ; « Solution » l'affiche.
  • « Claude » répond aux questions ou corrige le travail (serveur local : lancer.bat).

Sur le dessin

  • Double-clic sur le fond : nouvel élément ; sur un élément : le modifier.
  • « Relier », puis glisser d'un élément à l'autre. Suppr efface la sélection.
  • Glisser le fond déplace la vue ; Ctrl + molette zoome.

Chronogramme

Exercice 9 Ordonnancement FIFO

Trois processus arrivent sur un processeur : P1 à t = 0 (durée 3), P2 à t = 1 (durée 2), P3 à t = 2 (durée 4). Tracer le chronogramme de l'ordonnancement FIFO (x : exécution, p : prêt).

Quand une case ne vaut pas une unité de temps, on donne sa durée avec pas : ici, une case dure 50 µs, et les segments s'écrivent en microsecondes.

Pour un code en ligne, l'option niveaux dessine chaque ligne comme un signal, marques écrit les repères B et V sur les impulsions, et graduations met les bits à coder au-dessus des colonnes. Le champ papier reprend une réponse faite sur papier : la page s'ouvre avec elle tant que rien d'autre n'est enregistré (menu ⋯, « Reprendre ma copie papier »).

À retenir

L'essentiel

  • Un atelier est un bloc <div class="atelier" id="…" data-editeur="…"> qui contient ses données en JSON.
  • Dessin et vue texte sont synchronisés : on peut construire à la souris ou au clavier.
  • « Vérifier » contrôle la forme, « Comparer » l'écart avec la solution, Claude corrige sur le fond.
  • Le travail est enregistré dans le navigateur et, avec le serveur local, dans td_results/.

Auto-évaluation

Quelle différence entre « Vérifier » et « Comparer » ?

« Vérifier » contrôle la forme du travail (clé primaire manquante, multiplicité invalide…) sans rien dévoiler ; « Comparer » mesure l'écart avec la solution et liste les différences.

Un écart avec la solution est-il forcément une erreur ?

Non : un modèle admet souvent plusieurs réponses justes. La comparaison signale ce qui diffère ; en cas de doute, « Claude » juge sur le fond.

Où va le travail quand le serveur local tourne ?

Dans <Niveau>/<Matière>/td_results/<page>.json, un fichier par page ; sans serveur, il reste dans le navigateur.
